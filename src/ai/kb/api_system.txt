# Structure of a cartridge, time, system, saves, files.

== callbacks
kind: api
name: _update
title: _init, _update, _draw - la struttura di un gioco
ask: come è fatto un gioco | struttura di una cartuccia | game loop | ciclo del gioco
ask: dove metto la logica | dove disegno | funzioni principali | main loop
ask: quante volte al secondo | 60 fps | skeleton of a game | scheletro del gioco
see: game_skeleton
text:
_init() una volta all'avvio; poi 60 volte al secondo _update() (la logica:
input, movimento, collisioni) e _draw() (il disegno). Lua fa la logica, il
disegno è in C. Budget: 16,7 ms per fotogramma in tutto.
code:
function _init()
  x, y = 320, 180
end

function _update()
  if btn(1) then x = x + 2 end
end

function _draw()
  cls(0)
  circfill(x, y, 8, 0xFFD050)
end

== time
kind: api
name: time
title: time() - secondi dall'avvio del gioco
ask: quanto tempo è passato | secondi dall'inizio | elapsed time | orologio del gioco
ask: misurare il tempo | cronometro | time since start | durata della partita
see: timer, stat
text:
I secondi (con i decimali) da quando è partita la cartuccia. Per contare il
tempo di una partita salva time() all'inizio e fai la differenza.
code:
local start = time()
-- piu' tardi:
local s = time() - start
print(string.format("tempo %.1f s", s), 8, 8)

== stat
kind: api
name: stat
title: stat(n) - memoria, fps e tempi
ask: quanti fps fa il gioco | quanta memoria uso | frame rate | performance counters
ask: millisecondi per fotogramma | numero del fotogramma | memory used | cpu time
see: perf_measure, time
text:
0 KiB usati da Lua, 1 ms di CPU dell'ultimo fotogramma, 2 fps, 3 numero

== quit
kind: api
name: quit
title: quit() - chiude il gioco
ask: uscire dal gioco | chiudere la cartuccia | exit the game | tornare al menu
ask: terminare il programma | quit
see: callbacks
text:
Chiude la cartuccia alla fine del fotogramma. Esc, Start+Select o PS

== save
kind: api
name: save
title: save(t) - salva una tabella sulla SD
ask: salvare sulla sd | salvare i dati | save data | salvare il record
ask: memorizzare il punteggio | salvare le impostazioni | persist | savegame
see: saved, high_score
text:
Salva la tabella t (numeri, stringhe, booleani, tabelle; fino a 32 KiB):
true, oppure false e il motivo. Un salvataggio per cartuccia. Scrivere sulla
SD richiede qualche ms: salva a fine partita, non a ogni fotogramma.
code:
local ok, why = save({ best = best, level = level })
if not ok then log("salvataggio fallito: " .. why) end

== saved
kind: api
name: saved
title: saved() - la tabella salvata l'ultima volta
ask: caricare il salvataggio | leggere i dati salvati | load saved data
ask: recuperare il record | load game | caricare la partita
see: save, high_score
text:
La tabella salvata l'ultima volta con save(), oppure nil se non c'è.
code:
function _init()
  local d = saved()
  best = d and d.best or 0
end

== random
kind: api
name: math.random
title: math.random - numeri casuali
ask: numero casuale | numero a caso | random number | tirare un dado
ask: posizione casuale | scegliere a caso | random seed | casualità diversa ogni partita
see: rgb
text:
math.random() da 0 a 1, math.random(n) da 1 a n, math.random(a, b) da a a
b. Per partite diverse inizializza il generatore quando il giocatore preme
un tasto (il fotogramma cambia ogni volta).
code:
local dado = math.random(6)
local x = math.random(0, SCREEN_W - 16)
if btnp(4) then math.randomseed(stat(3)) end   -- al primo tasto

== cart_load
kind: api
name: cart_load
title: cart_load(percorso) - apre un .bm (per gli strumenti)
ask: aprire una cartuccia dal codice | caricare un file bm | load a cartridge file
ask: leggere il codice di un altro gioco | editor apre un file
see: cart_save, cart_new, ls
text:
Apre un .bm: il suo sprite sheet e la sua mappa sostituiscono quelli della
cartuccia che chiama. Restituisce {title, author, res, lua, sheet_w,
sheet_h, map_w, map_h}.
code:
local c = cart_load("/carts/PONG.BM")
log(c.title, #c.lua .. " byte di codice")

== cart_save
kind: api
name: cart_save
title: cart_save(percorso, {title, author, res, lua}) - scrive un .bm
ask: salvare una cartuccia | scrivere un file bm | save a cartridge | esportare il gioco
see: cart_load, cart_run

== cart_run
kind: api
name: cart_run
title: cart_run(percorso) e cart_arg() - prova un gioco e torna
ask: provare il gioco dall'editor | lanciare una cartuccia | run a cartridge
ask: tornare all'editor dopo la prova | errore del gioco provato
see: cart_save
text:
cart_run esce, gioca quel file e poi riapre la cartuccia che l'ha chiesto,
con cart_arg() = {path=, error=, back=true}: così l'editor sa se il gioco
si è fermato con un errore e su che riga.
code:
local a = cart_arg()
if a and a.error then
  log("errore: " .. a.error)
end

== require

== cart_read
kind: api
name: cart_read
title: cart_read(percorso) - legge il codice di un .bm (senza toccare altro)
ask: leggere il codice di un altro gioco | cart_read | read a cartridge's code

== cart_write
kind: api
name: cart_write
title: cart_write(percorso, {lua, title, author, res, from}) - scrive solo il codice
ask: salvare solo il codice di un bm | cart_write | write the code of a cartridge
ask: cambiare il codice senza perdere gli sprite | salvare con un altro nome
see: cart_read, cart_save
text: Cambia il codice (e titolo, autore, risoluzione se ci sono) di un .bm:
sprite sheet, mappa, copertina e ogni altra sezione restano com'erano. Un file
nuovo diventa una cartuccia con solo il codice (nome 8.3). from: le altre
sezioni vengono da un altro file ("salva come").
code:
local ok, err = cart_write("/carts/PONG.BM", { lua = code })
if not ok then log("non salvato: " .. err) end

== nnet
kind: api
name: nnet
title: nnet(blob) - una piccola rete neurale INT8 (bot, scelte del gioco)
ask: rete neurale nel gioco | nnet | far decidere un bot con una rete
ask: intelligenza artificiale per i nemici | small neural network for a game
ask: usare una rete addestrata sul pc | run a trained network in a cartridge
keys: rete, neurale, bot, neural, network
see: ai_ask
text: La rete di una stringa "BMNN" scritta da uno script di addestramento
(scripts/nnetlib.py: quantizza una rete di numpy in INT8). net:run(ingressi)
dà le uscite, net:pick(ingressi) l'indice della più grande (le tattiche dei
bot di Overbit), net:size() quanti ingressi e uscite. Pochi strati densi:
qualche microsecondo a chiamata.
code:
local net = nnet(BRAIN)
local k = net:pick({ hp, dist, enemies })

== udp
kind: api
name: udp_send
title: udp_open / udp_send / udp_recv - pacchetti UDP per giocare in rete
ask: giocare in rete | multiplayer online | mandare dati a un'altra console
ask: udp | send a packet on the network | network game | lan multiplayer
keys: rete, udp, multiplayer, online, lan, pacchetto
see: nnet
text: s = udp_open(porta) apre un socket (nil senza rete); udp_send(s, ind,
porta, dati) manda una stringa (al massimo 1024 byte, "*" = tutta la LAN);
udp_recv(s) dà il prossimo pacchetto e chi l'ha mandato, o nil. net_ip()
l'indirizzo della console. Overbit gioca in lockstep: viaggiano solo i
comandi dei giocatori.
code:
local s = udp_open(47310)
if s then udp_send(s, "*", 47310, "ciao") end
local d, ip = s and udp_recv(s)
