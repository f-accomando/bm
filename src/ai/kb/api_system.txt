# Structure of a cartridge, time, system, saves, files.

== callbacks
kind: api
name: _update
title: _init, _update, _draw - la struttura di un gioco
ask: come è fatto un gioco | struttura di una cartuccia | game loop | ciclo del gioco
ask: dove metto la logica | dove disegno | funzioni principali | main loop
ask: quante volte al secondo | 60 fps | skeleton of a game | scheletro del gioco
see: game_skeleton
text:
_init() una volta all'avvio; poi 60 volte al secondo _update() (la logica:
input, movimento, collisioni) e _draw() (il disegno). Lua fa la logica, il
disegno è in C. Budget: 16,7 ms per fotogramma in tutto.
code:
function _init()
  x, y = 320, 180
end

function _update()
  if btn(1) then x = x + 2 end
end

function _draw()
  cls(0)
  circfill(x, y, 8, 0xFFD050)
end

== time
kind: api
name: time
title: time() - secondi dall'avvio del gioco
ask: quanto tempo è passato | secondi dall'inizio | elapsed time | orologio del gioco
ask: misurare il tempo | cronometro | time since start | durata della partita
see: timer, stat
text:
I secondi (con i decimali) da quando è partita la cartuccia. Per contare il
tempo di una partita salva time() all'inizio e fai la differenza.
code:
local start = time()
-- piu' tardi:
local s = time() - start
print(string.format("tempo %.1f s", s), 8, 8)

== stat
kind: api
name: stat
title: stat(n) - memoria, fps e tempi
ask: quanti fps fa il gioco | quanta memoria uso | frame rate | performance counters
ask: millisecondi per fotogramma | numero del fotogramma | memory used | cpu time
see: perf_measure, time, guide.devkit
text:
0 KiB usati da Lua, 1 ms dell'ultimo fotogramma, 2 fps, 3 numero del
fotogramma, 4 triangoli 3D, 5 pixel 3D, 6 ms del disegno 3D, 7 vertici 3D,
8 ms da inizio fotogramma, 9 1 se il 3D lo fa la GPU, 10 istruzioni Lua
dell'ultimo fotogramma. Il dev kit: 11 token del codice, 12 KiB di Lua al
massimo, 13 KiB dei dati (sheet, mappa, modelli, suoni), 14 istruzioni del
fotogramma più pesante, 15 quanti _update prima di questo _draw.
code:
print(stat(2) .. " fps  " .. stat(1) .. " ms", 8, 8, 0x80FF80)
print(stat(0) .. " KiB", 8, 24, 0x80FF80)

== frameskip
kind: api
name: frameskip
title: frameskip(n) - il tempo del gioco anche quando il disegno è lento
ask: il gioco rallenta quando gli fps scendono | il gioco va al rallentatore | frame skip
ask: saltare fotogrammi | update più volte del draw | game slows down when fps drop
ask: tempo del gioco costante | fixed timestep
see: stat, guide.devkit, perf_tips
text:
Un gioco che avanza di 1/60 s a ogni _update rallenta quando un fotogramma
costa più di 16,7 ms. frameskip(n): prima di ogni _draw girano fino a n
_update, quanti ne servono per il tempo passato (i fotogrammi in mezzo non
si disegnano). 1 è il default (uno per fotogramma). btnp() conta un tasto
una volta sola; stat(15) dice quanti _update sono girati.
code:
function _init()
  frameskip(4)   -- fino a 4 _update per ogni _draw
end

== devkit
kind: api
name: devkit
title: devkit(modo) e devinfo(...) - l'overlay delle prestazioni dal gioco
ask: accendere il dev kit dal gioco | overlay delle prestazioni con il pad | show the performance overlay
ask: righe mie nel dev kit | aggiungere informazioni al dev kit | devinfo
see: guide.devkit, stat, frameskip
text:
devkit() dà il modo dell'overlay: 0 spento, 1 semplice, 2 dettagliato
(ogni fase del fotogramma, la GPU, i triangoli); devkit(modo) lo cambia,
per esempio con Select sul pad (F11 è della tastiera). devinfo(riga, ...)
mette fino a 4 righe del gioco nella pagina dettagliata.
code:
local enemies = {}
if btnp(9) then devkit((devkit() + 1) % 3) end   -- Select
if devkit() == 2 then devinfo("nemici " .. #enemies) end

== save
kind: api
name: save
title: save(t, [slot]) - salva una tabella sulla SD
ask: salvare sulla sd | salvare i dati | save data | salvare il record
ask: memorizzare il punteggio | salvare le impostazioni | persist | savegame
ask: salvare la partita nello slot 2 | save the game in a slot
see: saved, saves, high_score
text:
Salva la tabella t (numeri, stringhe, booleani, tabelle; fino a 32 KiB)
nello slot 1-8 (senza slot: l'1): true, oppure false e il motivo. Scrivere
sulla SD richiede qualche ms: salva a fine partita, non a ogni fotogramma.
code:
local ok, why = save({ best = best, level = level })
if not ok then log("salvataggio fallito: " .. why) end

== saved
kind: api
name: saved
title: saved([slot]) - la tabella salvata l'ultima volta

ask: recuperare il record | load game | caricare la partita
see: save, saves, high_score

La tabella salvata l'ultima volta con save() in quello slot (senza slot:

== saves
kind: api
name: saves
title: saves() - gli slot di salvataggio usati
ask: più salvataggi | più partite salvate | slot di salvataggio
ask: pagina carica partita | quali slot sono usati | save slots
ask: scegliere quale partita continuare | partite salvate da scegliere
ask: multiple save files | load game menu | list the saves | pick a saved game
see: save, saved, delsave
text:
Ogni cartuccia ha 8 slot. saves() dà {[slot] = byte} degli slot usati, e
quanti slot ci sono (8): per la pagina che sceglie la partita. Lo slot 1 è
quello di save(t) senza slot (record e impostazioni).
code:
local used = saves()
for i = 2, 4 do
  local p = used[i] and saved(i)
  print(p and ("livello " .. p.level) or "vuoto", 8, i * 10, 7)
end

== cart_run

== nnet
kind: api
name: nnet
title: nnet(blob) - una piccola rete neurale INT8 (bot, scelte del gioco)
ask: rete neurale nel gioco | nnet | far decidere un bot con una rete
ask: intelligenza artificiale per i nemici | small neural network for a game

== udp
kind: api
name: udp_send
title: udp_open / udp_send / udp_recv - pacchetti UDP per giocare in rete
ask: pacchetti udp | socket udp | mandare dati grezzi a un'altra console
ask: udp | send a raw packet on the network | udp socket | broadcast sulla lan
keys: udp, pacchetto, socket
see: bmnet, nnet
text: s = udp_open(porta) apre un socket (nil senza rete, o se il giocatore non
lo permette: la prima volta la console glielo chiede); udp_send(s, ind,
porta, dati) manda una stringa (al massimo 1024 byte, "*" = tutta la LAN);
udp_recv(s) dà il prossimo pacchetto e chi l'ha mandato, o nil. net_ip()
l'indirizzo della console. Overbit gioca in lockstep: viaggiano solo i
comandi dei giocatori.
code:
local s = udp_open(47310)
if s then udp_send(s, "*", 47310, "ciao") end
local d, ip = s and udp_recv(s)
