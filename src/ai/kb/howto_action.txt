== bullets
kind: howto
title: Sparare dei proiettili
title_en: Shooting bullets
ask: come sparo | sparare proiettili | shoot bullets | il giocatore spara
ask: lista di proiettili | colpi che si muovono | fire bullets | sparare con A
ask: proiettili che spariscono fuori dallo schermo
ask: sparare premendo un tasto | il personaggio spara
keys: sparare, proiettili, colpi, shoot
see: cooldown, enemies_list, collide_rect
text:
Una tabella di proiettili: si aggiungono quando spari, si muovono a ogni
fotogramma, si tolgono quando escono (scorrendo la lista all'indietro,
così table.remove non salta nessuno).
text_en:
A table of bullets: you add them when you shoot, move them every frame and
remove them when they go off the screen (walking the list backwards, so
table.remove skips none).
code:
bullets = {}

function _update()
  if btnp(4) then
    bullets[#bullets + 1] = { x = px + 4, y = py, vy = -6 }
  end
  for i = #bullets, 1, -1 do
    local b = bullets[i]
    b.y = b.y + b.vy
    if b.y < -8 then table.remove(bullets, i) end
  end
end

function _draw()
  for _, b in ipairs(bullets) do rectfill(b.x, b.y, 2, 6, 0xFFE060) end
end

== enemies_list
kind: howto
title: Tanti nemici in una lista
title_en: Many enemies in a list
ask: tanti nemici | lista di nemici | gestire più nemici | multiple enemies
ask: aggiungere e togliere nemici | ciclo sui nemici | enemy table | orde
keys: nemici, lista, enemies
see: bullets_hit, chase, spawn_waves
text:
Ogni nemico è una tabella; tutti in una lista. Per toglierli mentre la
scorri, scorrila all'indietro.
text_en:
Each enemy is a table; all of them go in a list. To remove them while you
walk the list, walk it backwards.
code:
enemies = {}

function spawn(x, y)
  enemies[#enemies + 1] = { x = x, y = y, hp = 3 }
end

function update_enemies()
  for i = #enemies, 1, -1 do
    local e = enemies[i]
    e.y = e.y + 1
    if e.hp <= 0 or e.y > SCREEN_H then table.remove(enemies, i) end
  end
end

== bullets_hit
kind: howto
title: I proiettili colpiscono i nemici
title_en: Bullets hit the enemies
ask: proiettili che colpiscono i nemici | uccidere i nemici | bullet enemy collision
ask: il colpo distrugge il nemico | punti quando colpisco | hit detection
keys: colpire, distruggere, uccidere
see: bullets, enemies_list, collide_rect
text:
Per ogni proiettile, prova ogni nemico; al primo colpito il proiettile
sparisce.
text_en:
For each bullet, test each enemy; at the first one hit the bullet
disappears.
code:
for i = #bullets, 1, -1 do
  local b = bullets[i]
  for _, e in ipairs(enemies) do
    if b.x > e.x and b.x < e.x + 16 and
       b.y > e.y and b.y < e.y + 16 then
      e.hp = e.hp - 1
      score = score + 10
      table.remove(bullets, i)
      break
    end
  end
end

== particles
kind: howto
title: Particelle (esplosioni, scintille, fumo)
title_en: Particles (explosions, sparks, smoke)
ask: particelle | esplosione di particelle | scintille | particles effect | fumo
ask: effetto quando un nemico muore | detriti | sangue | coriandoli
ask: snippet per un effetto particelle | sprite particle effect | effetto particelle per uno sprite
keys: particelle, scintille, esplosione
see: screen_shake, sfx_examples, lib.particles
text:
Tanti puntini con velocità a caso che vivono pochi fotogrammi.
text_en:
Lots of dots with random speeds that live a few frames.
code:
parts = {}

function boom(x, y)
  for i = 1, 20 do
    local a, s = math.random() * 6.28, math.random() * 3
    parts[#parts + 1] = { x = x, y = y, vx = math.cos(a) * s,
                          vy = math.sin(a) * s, t = 30 }
  end
end

function draw_parts()
  for i = #parts, 1, -1 do
    local p = parts[i]
    p.x, p.y, p.t = p.x + p.vx, p.y + p.vy, p.t - 1
    pset(p.x, p.y, p.t > 15 and 0xFFE060 or 0xFF6020)
    if p.t <= 0 then table.remove(parts, i) end
  end
end

== hitbox_frames
kind: howto
title: Hitbox per fotogramma da uno sprite animato (picchiaduro)
title_en: Per-frame hitboxes from an animated sprite (fighting game)
ask: hitbox che cambiano con l'animazione | il pugno colpisce solo in un fotogramma
ask: hitbox per ogni fotogramma | frame by frame hitboxes | attacco con fotogrammi attivi
ask: hurtbox che seguono lo sprite | riquadri dei colpi disegnati nello sheet
keys: fotogramma, hitbox, animazione, attivi
see: zboxes, lib.hits, lib.box
text:
Nel file delle zone (mkbm.py --sprites) sotto la zona: "hurt * x y w h"
per tutti i fotogrammi, "hit 3 x y w h" per il fotogramma attivo. Nel
gioco H:zone mette nel mondo quelli del fotogramma disegnato, specchiati
se guarda a sinistra; l'id dell'attacco fa colpire una volta.
text_en:
In the zones file (mkbm.py --sprites), under the zone: "hurt * x y w h"
for all the frames, "hit 3 x y w h" for the active frame. In the game
H:zone puts into the world the boxes of the frame drawn, mirrored if it
faces left; the id of the attack makes it hit once.
code:
H:clear()
H:zone(p1, "pugno", p1.frame, p1.x, p1.y, p1.face < 0,
       { team = 1, attack = { id = p1.swing, damage = 5 } })
H:zone(p2, "fermo", 1, p2.x, p2.y, p2.face < 0, { team = 2 })
for _, c in ipairs(H:check()) do
  c.to.life = c.to.life - c.hit.damage
end
