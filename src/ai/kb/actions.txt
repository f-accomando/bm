# Actions on the code: what a line "#entry: request #" in bm Code asks the
# assistant to do on the function around the line, or right below it
# (src/ai/assist.lua, assist.act). gen: the action.

== act.ternary
kind: action
gen: ternary
title: Operatore ternario (if/else -> cond and a or b)
title_en: Ternary operator (if/else -> cond and a or b)
ask: aggiungi operatore ternario su questa funzione | usa l'operatore ternario
ask: trasforma gli if in ternario | ternario | ternary operator | use the ternary operator
ask: semplifica if else in una riga | if else su una riga sola | convert if else to and or
ask: rendi più compatti gli if | accorcia gli if else
text: Un if/else che assegna la stessa variabile (o restituisce un valore)
diventa "x = cond and a or b". Attenzione: a non deve mai essere nil o false.
text_en: An if/else that assigns the same variable (or returns a value)
becomes "x = cond and a or b". Careful: a must never be nil or false.
