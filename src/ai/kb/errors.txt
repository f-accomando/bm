# Lua errors: what the message means and how to fix it. The panel opened on
# an error (mode "error") asks with the message itself, without the
# "main.lua:12:" in front, and adds the line and a mistyped name.

== err_call_nil
kind: error
title: attempt to call a nil value - funzione che non esiste
title_en: attempt to call a nil value - a function that does not exist
ask: attempt to call a nil value (global 'foo') | attempt to call a nil value
ask: attempt to call a nil value (method 'update') | attempt to call a nil value (field 'draw')
ask: la funzione non esiste | errore chiamando una funzione | funzione nil
keys: call, nil
see: err_index_nil, lua_functions
text:
Chiami una funzione che non c'è: il nome è scritto male (spr ->
"sprr"), oppure la funzione è definita più in basso come local e chi la
chiama sta sopra, oppure la tabella non ha quel metodo. Il nome è tra gli
apici nel messaggio.
text_en:
You call a function that is not there: the name is misspelled (spr ->
"sprr"), or the function is defined further down as local and its caller
is above it, or the table does not have that method. The name is between
the quotes in the message.
code:
-- sbagliato: la local e' definita dopo chi la usa
-- local function a() b() end
-- local function b() end
-- giusto: dichiara prima
local b
local function a() b() end
function b() log("ok") end

== err_index_nil
kind: error
title: attempt to index a nil value - tabella che non esiste
title_en: attempt to index a nil value - a table that does not exist
ask: attempt to index a nil value (global 'player') | attempt to index a nil value
ask: attempt to index a nil value (field 'pos') | attempt to index a nil value (local 'e')
ask: errore con il punto | la tabella è nil | variabile nil con il punto
keys: index, nil
see: err_call_nil, lua_local
text:
Usi t.x o t[i] ma t è nil: la tabella non è stata creata (manca t = {}),
il nome è scritto male, o l'elemento della lista non esiste (indice oltre
la fine). Crea la tabella prima o controlla che non sia nil.
text_en:
You use t.x or t[i] but t is nil: the table was not created (t = {} is
missing), the name is misspelled, or the element of the list does not
exist (an index past the end). Create the table first or check that it
is not nil.
code:
player = { x = 0, y = 0 }      -- crea prima di usarla
local e = enemies[i]
if e then e.x = e.x + 1 end    -- controlla prima

== err_arith_nil
kind: error
title: attempt to perform arithmetic on a nil value - conto con nil
title_en: attempt to perform arithmetic on a nil value - a calculation with nil
ask: attempt to perform arithmetic on a nil value (global 'score')
ask: attempt to perform arithmetic on a nil value | attempt to perform arithmetic on a nil value (field 'x')
ask: errore sommando | variabile nil nel calcolo | arithmetic on nil
keys: arithmetic, nil
see: err_index_nil, lua_local
text:
Una variabile del calcolo è nil: non le hai dato un valore iniziale (in
_init o in cima al file) oppure il nome è scritto diverso.
text_en:
A variable of the calculation is nil: you did not give it a starting
value (in _init or at the top of the file) or the name is spelled
differently.
code:
score = 0                       -- in _init: il valore iniziale
score = score + 10
t = (t or 0) + 1                -- oppure: 0 se ancora nil

== err_compare_nil
kind: error
title: attempt to compare number with nil - confronto con nil
title_en: attempt to compare number with nil - a comparison with nil
ask: attempt to compare number with nil | attempt to compare nil with number
ask: attempt to compare two nil values | errore nel confronto | if con nil
keys: compare, nil
see: err_arith_nil
text:
In un <, >, <= o >= uno dei due valori è nil: la variabile non ha ancora
un valore. == e ~= invece funzionano anche con nil.
text_en:
In a <, >, <= or >= one of the two values is nil: the variable does not
have a value yet. But == and ~= work with nil too.
code:
hp = hp or 3                    -- un valore prima del confronto
if hp < 1 then state = "over" end

== err_end_expected
kind: error
title: 'end' expected - manca un end
title_en: 'end' expected - an end is missing
ask: 'end' expected (to close 'function' at line 3) near <eof> | 'end' expected
ask: 'end' expected (to close 'if' at line 10) near 'function' | manca un end
keys: end, expected
see: err_eof_expected
text:
Ogni function, if, for e while si chiude con end. Il messaggio dice quale
blocco è aperto e a che riga comincia: conta gli end da lì. Il rientro del
codice aiuta a vedere dove manca.
text_en:
Every function, if, for and while is closed with end. The message says
which block is open and on which line it starts: count the ends from
there. The indentation of the code helps you see where one is missing.
code:
function _update()
  if btn(0) then
    x = x - 1
  end            -- chiude l'if
end              -- chiude la function

== err_eof_expected
kind: error
title: <eof> expected near 'end' - un end di troppo
title_en: <eof> expected near 'end' - one end too many
ask: <eof> expected near 'end' | '<eof>' expected near 'end' | un end di troppo
keys: eof, end
see: err_end_expected
text:
C'è un end in più: Lua ha chiuso tutti i blocchi e ne trova un altro.
Spesso è un if su una riga sola (if ... then ... end) seguito da un end.
text_en:
There is one end too many: Lua has closed all the blocks and finds
another one. Often it is an if on a single line (if ... then ... end)
followed by an end.
code:
if btn(0) then x = x - 1 end   -- l'if su una riga ha gia' il suo end

== err_then_expected
kind: error
title: 'then' expected - manca il then dell'if
title_en: 'then' expected - the if is missing its then
ask: 'then' expected near 'x' | 'then' expected | manca then | errore nell'if
ask: 'do' expected near | manca do nel for
keys: then, do, expected
see: lua_if
text:
Dopo la condizione di un if serve then (e dopo for e while serve do).
Attenzione anche a = invece di == nella condizione.
text_en:
After the condition of an if you need then (and after for and while you
need do). Also watch out for = instead of == in the condition.
code:
if x == 10 then      -- == per confrontare, poi then
  x = 0
end
for i = 1, 3 do log(i) end

== err_equals_expected
kind: error
title: '=' expected - istruzione incompleta
title_en: '=' expected - an incomplete statement
ask: '=' expected near 'x' | '=' expected | syntax error near | errore di sintassi
keys: expected, sintassi
see: err_unexpected_symbol
text:
Lua ha letto un nome e si aspettava un'assegnazione: spesso è una parola
scritta male all'inizio della riga (Locale invece di local), uno spazio
dentro un nome o una chiamata senza parentesi.
text_en:
Lua has read a name and expected an assignment: often it is a misspelled
word at the start of the line (Locale instead of local), a space inside
a name or a call without parentheses.
code:
local speed = 2       -- non "Local speed = 2"
player_x = 10         -- non "player x = 10"
cls()                 -- non "cls"

== err_unexpected_symbol
kind: error
title: unexpected symbol - carattere al posto sbagliato
title_en: unexpected symbol - a character in the wrong place
ask: unexpected symbol near | unexpected symbol near '}' | unexpected symbol near ')'
ask: simbolo inatteso | parentesi in più | virgola sbagliata
keys: unexpected, symbol
see: err_equals_expected
text:
Un carattere che lì non ha senso: una parentesi in più o in meno, una
virgola dopo l'ultimo argomento, += (in Lua non esiste: x = x + 1),
!= invece di ~=.
text_en:
A character that makes no sense there: one parenthesis too many or too
few, a comma after the last argument, += (it does not exist in Lua:
x = x + 1), != instead of ~=.
code:
x = x + 1             -- non x += 1
if a ~= b then end    -- non a != b

== err_unfinished_string
kind: error
title: unfinished string - manca la virgoletta di chiusura
title_en: unfinished string - the closing quote is missing
ask: unfinished string near | stringa non chiusa | manca una virgoletta
keys: unfinished, string
see: lua_strings

Una stringa aperta con " o ' non è chiusa sulla stessa riga. Per un

A string opened with " or ' is not closed on the same line. For an

== err_timeout
kind: error
title: cart timeout - ciclo infinito
title_en: cart timeout - an endless loop
ask: cart timeout: more than 20 million instructions in one frame | cart timeout
ask: il gioco si blocca | ciclo infinito | infinite loop | il gioco si ferma senza motivo
keys: timeout, infinito, blocca
see: lua_loops, perf_tips
text:
Un fotogramma ha eseguito più di 20 milioni di istruzioni: quasi sempre un
while che non finisce mai (la condizione non cambia dentro il ciclo).
text_en:
A frame has run more than 20 million instructions: almost always a while
that never ends (the condition does not change inside the loop).
code:
local i = 1
while i <= #list do
  -- ...
  i = i + 1        -- senza questa riga il while non finisce
end

== err_memory
kind: error
title: not enough memory - memoria finita
title_en: not enough memory - out of memory
ask: not enough memory | memoria esaurita | out of memory | il gioco usa troppa memoria
keys: memory, memoria
see: perf_tips, stat
text:
Le tabelle crescono senza fine: per esempio proiettili o particelle che
non vengono mai tolti dalla lista. stat(0) mostra i KiB usati.
text_en:
Tables keep growing: for example bullets or particles that are never
removed from the list. stat(0) shows the KiB in use.
code:
for i = #bullets, 1, -1 do
  if bullets[i].y < 0 then table.remove(bullets, i) end

== err_bad_argument
kind: error
title: bad argument - argomento sbagliato a una funzione
title_en: bad argument - a wrong argument to a function
ask: bad argument #1 to 'spr' (number expected, got nil) | bad argument
ask: bad argument #2 to 'print' (number expected, got no value) | number expected, got nil
keys: argument, expected
see: err_arith_nil
text:
Il numero dopo # è la posizione dell'argomento sbagliato, poi la funzione.
"got nil" o "got no value": una variabile non ha valore o mancano
argomenti (print vuole testo, x e y).
text_en:
The number after # is the position of the wrong argument, then comes the
function. "got nil" or "got no value": a variable has no value or some
arguments are missing (print wants the text, x and y).
code:
print("ciao", 8, 8)            -- print(testo, x, y)
spr(n or 0, x, y)

== err_stack_overflow
kind: error
title: stack overflow - funzione che chiama sé stessa all'infinito
title_en: stack overflow - a function that calls itself forever
ask: stack overflow | ricorsione infinita | infinite recursion | la funzione chiama se stessa
keys: stack, overflow, ricorsione
see: lua_functions
text:
Una funzione chiama sé stessa (o due funzioni si chiamano a vicenda) senza
mai fermarsi. Serve una condizione di uscita.
text_en:
A function calls itself (or two functions call each other) without ever
stopping. It needs an exit condition.
code:
local function fill(x, y)
  if x < 0 or y < 0 or x > 79 or y > 44 then return end
  if mget(x, y) ~= 0 then return end
  mset(x, y, 1)
  fill(x + 1, y); fill(x - 1, y); fill(x, y + 1); fill(x, y - 1)
end
