== lua_tables
kind: howto
title: Lua: liste e tabelle

ask: lua table | array in lua | togliere un elemento | lunghezza della lista
ask: table.insert e table.remove | dizionario | chiave e valore
keys: tabella, lista, array, table
see: lua_loops, enemies_list
text:

log(#list, p.x, p["y"])

== lua_objects
kind: howto
title: Lua: oggetti con metodi (classi)
ask: classi in lua | oggetti con metodi | programmazione a oggetti | metatable
ask: creare tanti nemici dello stesso tipo | object oriented | self
keys: classe, oggetto, metodo, self
see: enemies_list
text:
Una tabella fa da classe: setmetatable dà ai nuovi oggetti i suoi metodi;
con i due punti (e:update()) il metodo riceve l'oggetto come self.
code:
local Enemy = {}
Enemy.__index = Enemy

function Enemy.new(x, y)
  return setmetatable({ x = x, y = y, hp = 3 }, Enemy)
end

function Enemy:update()
  self.x = self.x + 1
end

local e = Enemy.new(10, 20)
e:update()

== lua_coroutines
kind: howto
title: Lua: sequenze con le coroutine (scene, cutscene)
ask: sequenza di azioni nel tempo | cutscene | aspettare dentro una funzione
ask: coroutine | script di una scena | fare una cosa dopo l'altra | wait
ask: eventi in sequenza con attese | prima una cosa poi un'altra con una pausa
keys: coroutine, sequenza, cutscene
see: timer
text:
Una coroutine si ferma con yield e riparte al fotogramma dopo: si scrive
una sequenza come una storia, con le attese dentro.
code:
local function wait(frames)
  for i = 1, frames do coroutine.yield() end
end

local scene = coroutine.create(function()
  say = "Benvenuto!"; wait(120)
  say = "Trova la chiave."; wait(120)
  say = nil
end)

function _update()
  if coroutine.status(scene) ~= "dead" then coroutine.resume(scene) end
end
