# Sound: 8 voices of synthesis, HDMI output; the sound bank of the
# cartridge (Sound editor) and the notes played from the code.

== sfx
kind: api
name: sfx
title: sfx(n, [v, semitoni, vol]) - un effetto sonoro del banco
ask: suonare un effetto sonoro del banco | effetto fatto con il sound editor
ask: play a sound effect | suono del salto dal banco | sfx del banco di suoni
ask: suonare l'effetto numero 3 | effetto un'ottava sopra | fermare gli effetti
keys: sfx, banco, effetto
see: music, sfx_examples, note
text:
Suona l'effetto sonoro n del banco della cartuccia (fatto con il Sound
editor della scheda Dev). Senza v sceglie una voce libera; semitoni lo
traspone, vol 0-1. sfx(-1) ferma gli effetti. Restituisce la voce, o nil
se la cartuccia non ha un banco.
code:
if btnp(4) then sfx(1) end         -- salto
sfx(0, nil, 12)                    -- la moneta, un'ottava sopra
sfx(-1)                            -- ferma tutti gli effetti

== music
kind: api
name: music
title: music(n, [fade_ms, pos]) - un brano del banco
ask: far partire la musica del banco | suonare il brano fatto con il sound editor
ask: play music | fermare la musica | musica che sfuma | cambiare brano
ask: music del banco di suoni | musica del livello | stop music
keys: music, brano, banco
see: sfx, tempo, music_loop
text:
Suona il brano n del banco (in loop se così è nell'editor), con una
dissolvenza di fade_ms. music(-1, ms) la ferma sfumando; music() mentre
suona dice brano, posizione, passo e pattern.
code:
function _init()
  music(0)                         -- il brano 0
end
-- alla fine del livello:
music(-1, 500)                     -- sfuma in mezzo secondo

== tempo
kind: api
name: tempo
title: tempo(x) e mute(traccia, [on]) - velocità e strati della musica
ask: musica più veloce quando il gioco si fa difficile | accelerare la musica
ask: spegnere una traccia della musica | strati della musica | music speed
ask: mute di una traccia | musica dinamica
keys: mute, traccia, accelerare
see: music
text:
tempo(x): la musica del banco va x volte più veloce (1 = come scritta).
mute(t) spegne la traccia t della musica, mute(t, false) la riaccende:
strati che entrano e escono.
code:
if boss then tempo(1.2) else tempo(1) end
mute(3)                            -- via la batteria
mute(3, false)                     -- torna

== slide
kind: api
name: slide
title: slide(v, hz, [ms]) - la nota scivola a un'altra altezza
ask: glissando | sirena | suono che sale | effetto laser che scende | pitch bend
ask: nota che scivola | slide | portamento
keys: slide, glissando, sirena
see: note, freq, vibrato
text:
La nota della voce v scivola fino a hz in ms millisecondi (100): laser,
sirene, cadute. hz anche come nome di nota ("C5").
code:
note(1, 1300, 300, SQUARE, 70)     -- laser: parte alto...
slide(1, 300, 250)                 -- ...e scende

== arp
kind: api
name: arp
title: arp(v, accordo, [ms]) - arpeggio
ask: arpeggio | accordo arpeggiato | suonare un accordo | chord
ask: accordo maggiore | arpeggio come le console a 8 bit | arp
keys: arpeggio, accordo, arp
see: note, hz
text:
La nota della voce v percorre un accordo, ms per nota (50): "major",
"minor", "maj7", "min7", "7", "sus2", "sus4", "dim", "aug", "power",

code:

== hz
kind: api
name: hz
title: hz(nota) - la frequenza di una nota
ask: frequenza di una nota | nome della nota in hertz | do centrale | la 440
ask: convertire nota midi in frequenza | note name to frequency
keys: hz, midi
see: note
text:
La frequenza di una nota: un numero MIDI (60 = do centrale, 69 = la 440)
o un nome ("A4"). note accetta anche direttamente i nomi: note(0, "C4").
code:
local f = hz("A4")                 -- 440
note(0, hz(60 + 7), 200, TRIANGLE)  -- sol sopra il do centrale

== note
kind: api
name: note
title: note(v, hz, [ms], [forma], [vol]) - suona una nota
ask: suonare una nota | fare un suono | play a sound | emettere un beep
ask: effetto sonoro | suono quando salto | play a note | blip | audio
ask: frequenza in hertz | onda quadra | volume del suono
see: noteoff, envelope, sfx, sfx_examples
text:
Suona sulla voce v (0-7) una nota di hz Hertz (o un nome: "C4", "F#3");
con ms si spegne da sola. Forme: SQUARE, TRIANGLE, SAW, NOISE, SINE, METAL.
vol 0-255 (128). Una voce per tipo di suono, così un effetto non
interrompe l'altro. Gli effetti fatti con il Sound editor: sfx(n).
code:
note(0, 880, 60, SQUARE, 100)      -- blip
note(0, "C5", 60, SQUARE, 100)     -- lo stesso, con il nome
note(1, 220, 200, TRIANGLE, 120)   -- nota bassa e morbida
note(2, 2500, 300, NOISE, 130)     -- rumore: esplosione

== noteoff
kind: api
name: noteoff
title: noteoff(v) - rilascia la nota
ask: fermare un suono | spegnere una nota | stop a sound | silenzio | nota che non finisce
see: note, playing
text:
Rilascia la nota della voce v (parte la fase di release dell'inviluppo).
Una nota senza ms resta accesa finché non la spegni.
code:
note(3, 440, nil, SAW, 90)    -- resta accesa
-- piu' tardi:
noteoff(3)

== freq
kind: api
name: freq
title: freq(v, hz) - cambia l'altezza senza ripartire
ask: cambiare la nota mentre suona | cambiare altezza senza ripartire
ask: frequenza che segue il gioco | change frequency | motore che sale di giri
see: note, slide
text:
Cambia l'altezza della voce v senza ripartire l'inviluppo, un passo per
fotogramma in _update: suoni che seguono il gioco. Per un glissando
semplice c'è slide.
code:
note(1, 1300, 100, SQUARE, 70)
laser = 6
-- in _update:
if laser > 0 then laser = laser - 1; freq(1, 400 + laser * 150) end

== envelope
kind: api
name: envelope
title: envelope(v, a, d, s, r) - inviluppo ADSR della voce
ask: inviluppo adsr | attacco e rilascio del suono | sound envelope | suono che sfuma
ask: suono che si smorza | decay | fade out del suono
see: note
text:
Attack, decay e release sono tempi 0-255 (0 istantaneo, 255 = 2 s),
sustain un livello 0-255. Predefinito 1, 0, 255, 10.
code:
envelope(2, 0, 60, 0, 30)          -- colpo che si smorza
note(2, 2500, 300, NOISE, 130)     -- esplosione

== tone
kind: api
name: tone
title: tone(v, suono) - il timbro della voce: strumenti pronti e filtro
ask: suonare le note con il pianoforte | cambiare strumento a una voce
ask: un suono meno 8 bit | suono più morbido | filtro passa basso | cutoff
ask: strumento pronto per note | electric piano sound | change the instrument
ask: basso con il filtro risonante | suono a destra o a sinistra | pan stereo
keys: timbro, strumento, filtro, cutoff, risonanza, pan, stereo
see: play, instruments, reverb, note
text:
Il timbro della voce v per le note() che seguono: il nome di uno strumento
pronto ("epiano", "pluck", "pad", "bass", "kick"...: instruments()) o una
tabella con le chiavi che cambiano: preset, wave, attack, decay, sustain,
release (ms), cutoff (Hz), res, filter ("lp", "bp", "hp"), fenv, fdecay,
pan (-1 sinistra, 1 destra), reverb, echo, drive, lfo, wah, raw (8 bit).
tone(v) torna alla voce di partenza.
code:
tone(0, "epiano")
note(0, "E4", 400)
tone(1, { preset = "bass", cutoff = 300, res = 0.7, pan = -0.3 })
note(1, "E2", 300)

== play
kind: api
name: play
title: play([v], suono, [nota, ms, vol]) - suonare uno strumento
ask: suonare uno strumento pronto | suonare la cassa della batteria
ask: play an instrument | suono di batteria dal codice | rullante e charleston
ask: suonare un suono del banco con un'altra nota | colpo di cassa
keys: strumento, batteria, cassa, rullante
see: tone, instruments, sfx
text:
Suona uno strumento come lo suona la musica, con il suo inviluppo
dell'altezza e il vibrato (la cassa che scende, il laser): un nome, una
tabella come quella di tone() (più pitch, ptime, vib) o un suono del banco
(un numero). nota: MIDI o nome ("C4"), ms 0 = tenuta fino a noteoff, vol
0-1. Senza v sceglie una voce libera; restituisce la voce.
code:
play(nil, "kick", "C2")
play(nil, "snare", "D3", 0, 0.8)
local v = play(nil, "pad", "A3", 0)
-- dopo: noteoff(v)

== reverb
kind: api
name: reverb
title: reverb([grandezza, smorzo, livello]), echo([ms, ritorno, livello])
ask: aggiungere il riverbero | suono in una cattedrale | ambiente della musica
ask: add reverb | eco del suono | echo delay | eco a tempo con la musica
ask: suono in una grotta | suono che rimbomba in una sala
keys: riverbero, ambiente, eco, sala, grotta
see: tone, retro
text:
reverb: l'ambiente delle voci (0-1: da una stanza piccola a una sala,
da brillante a sordo, quanto si sente). echo: l'eco a ping-pong, ms tra
le ripetizioni (fino a 680), quanto torna (0-0.95), quanto si sente.
Quanto ci manda ogni voce lo dicono reverb ed echo di tone().
code:
reverb(0.8, 0.5, 1)            -- una cattedrale
echo(375, 0.4, 1)              -- a tempo a 80 BPM
tone(2, { preset = "lead", echo = 0.5 })

== play_at
kind: api
name: play_at
title: play_at(t, suono, [nota, ms, vol, tag]) - una nota a un tempo preciso
ask: suonare una nota a un tempo preciso | nota in tempo senza ritardi
ask: play a note at an exact time | sequencer preciso dal codice
ask: musica che non rallenta col gioco | audio_time orologio del suono
keys: tempo, preciso, orologio, coda
see: play, riff
text:
Mette in coda una nota per il tempo t di audio_time() (secondi):
la fa partire l'interrupt del suono, entro 1,3 ms, anche se il gioco
rallenta. suono come in play(); tag 1-255 raggruppa le note per
play_cancel(tag). La voce si sceglie quando parte (play_voices).
code:
local t = audio_time()
for i = 0, 3 do
  play_at(t + i * 0.25, "kick", "C2", 100)
end

== riff
kind: api
name: riff
title: require "riff" - musica in pattern, come Strudel
ask: scrivere un ritmo in una riga come strudel | musica a pattern come tidal
ask: live coding della musica | strudel su bm | pattern musicali in lua
ask: write music as patterns like strudel | drum pattern in one line
ask: mini notazione dei ritmi | sequencer a pattern | algorave
keys: riff, strudel, tidal, pattern, mininotazione
see: riff_code, riff_mini, play_at
text:
Ritmi e melodie scritti in una stringa (mini-notazione) e cambiati
da funzioni concatenate con i due punti; R.play(nome, p) li suona,
R.update() in _update li tiene in tempo. Strumenti pronti e suoni del
banco per nome; le unita' sono quelle di tone(). Guida: docs/RIFF.md.
code:
local R = require "riff"
R.play("drums", R.s "kick*4, ~ snare, hat*8")
R.play("bass", R.note "<c2 a1 f1 g1>" :s "acid" :lpf(800))
function _update() R.update() end

== riff_code
kind: api
name: riff.code
title: riff.code(testo) - musica dal vivo, una globale per pattern
ask: codice musicale dal vivo | cambiare la musica mentre suona
ask: riff code | tante tracce di musica con un nome
ask: live code music while it plays | suonare piu' pattern insieme
keys: riff, dal vivo, live
see: riff, riff_live
text:
Esegue un pezzo di Lua dove note, s, chord, stack, sine, setcpm...
sono globali: ogni globale con un pattern suona con quel nome (_nome
no), quelle di prima non piu' nominate si fermano. true, o nil e
l'errore (la musica continua). In bm Code: Ctrl+Invio.
code:
local R = require "riff"
R.code [[
setcpm(30)
drums = s "kick ~ ~ kick, ~ snare, hat*8?"
arp = chord "<Am F C G>" :s "pluck" :arp("updown") :fast(4)
]]

== riff_mini
kind: howto
title: La mini-notazione di riff: ~ [ ] < > * / ! @ ? ( )
ask: come si scrive un ritmo nella stringa | cosa vuol dire <a b> e [a b]
ask: ritmo euclideo 3 su 8 | pausa nel pattern | mini-notation syntax
ask: suonare una nota ogni ciclo diversa | hat*8 cosa fa
ask: il significato dei simboli nella stringa del ritmo | parentesi angolari nel pattern
ask: what do the brackets mean in a riff string | note diverse a ogni giro
keys: mininotazione, euclideo, pausa, ciclo
see: riff, riff_code
text:
Una stringa e' un ciclo diviso in parti: "a b c d". ~ pausa, [a b]
un gruppo in una parte, a,b insieme, <a b> una per ciclo, a*2 piu'
veloce, a/2 piu' lenta, a!3 ripetuta, a@3 piu' lunga, a? a caso,
a(3,8) euclideo, {a b c}%4 polimetro, a|b una delle due.
code:
local R = require "riff"
R.play("beat", R.s "kick(3,8), [~ hat]*4, ~ <snare clap>")
R.play("mel", R.n "0 [2 4] <7 6> ~" :scale("C:minor") :s "pluck")

== riff_live
kind: howto
title: Suonare la musica dal vivo in bm Code (Ctrl+Invio)
ask: sentire la musica mentre scrivo il codice | suonare il codice in bm code
ask: ctrl invio suona | fermare la musica in bm code | live coding bm code
ask: play the code as music in the editor
keys: dal vivo, ctrl, invio, suona
see: riff_code, riff
text:
In bm Code Ctrl+Invio suona la scheda (in un gioco il blocco
riff.code [[ ]] sotto il cursore): le parole delle note si accendono
mentre suonano, un errore segna la riga e la musica continua.
