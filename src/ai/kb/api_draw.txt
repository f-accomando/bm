== cls
kind: api
name: cls
title: cls([c]) - cancella lo schermo
title_en: cls([c]) - clears the screen
ask: come cancello lo schermo | pulire lo schermo | colore dello sfondo | clear the screen
ask: riempire lo schermo di un colore | background color | schermo nero | sfondo blu
ask: lo schermo resta sporco | le immagini lasciano la scia | trails on the screen
see: rgb, rectfill
text:
Riempie tutto lo schermo con il colore c (nero se manca). Lo schermo non si
cancella da solo: di solito _draw() comincia con cls(), altrimenti quello
che si muove lascia la scia.
text_en:
Fills the whole screen with colour c (black if missing). The screen does
not clear by itself: usually _draw() starts with cls(), otherwise what
moves leaves a trail.
code:
function _draw()
  cls(0x102040)          -- sfondo blu scuro
  circfill(320, 180, 20, 0xFFD050)
end

== pset
kind: api
name: pset
title: pset(x, y, c) - accende un pixel
title_en: pset(x, y, c) - lights up a pixel
ask: disegnare un pixel | colorare un punto | set a pixel | draw a single pixel
ask: puntino sullo schermo | stelle sullo sfondo | plot a point
see: pget, line
text:
Colora il pixel in x, y. Per tanti punti (un cielo stellato) va bene: il
costo è la chiamata da Lua, qualche microsecondo l'una.
text_en:
Colours the pixel at x, y. For many points (a starry sky) it is fine: the
cost is the call from Lua, a few microseconds each.
code:
for i = 1, 100 do
  local x = math.random(0, SCREEN_W - 1)
  local y = math.random(0, SCREEN_H - 1)
  pset(x, y, 0xFFFFFF)
end

== pget
kind: api
name: pget
title: pget(x, y) - legge il colore di un pixel
title_en: pget(x, y) - reads the colour of a pixel
ask: leggere il colore di un pixel | che colore c'è in un punto | get pixel color
ask: colore sotto il personaggio | read a pixel from the screen
see: pset, sget, mget
text:
Restituisce il colore 0xRRGGBB del pixel in x, y, o nil fuori dallo
schermo. Per le collisioni con la mappa è meglio mget(): non dipende da
cosa è già stato disegnato.
text_en:
Returns the colour 0xRRGGBB of the pixel at x, y, or nil outside the
screen. For collisions with the map mget() is better: it does not depend
on what has already been drawn.
code:
local c = pget(x, y)
if c == 0xFF0000 then log("pixel rosso") end

== rectfill
kind: api
name: rectfill
title: rectfill(x, y, w, h, c) - rettangolo pieno
title_en: rectfill(x, y, w, h, c) - filled rectangle
ask: disegnare un rettangolo pieno | quadrato colorato | draw a filled rectangle
ask: barra colorata | sfondo di un pannello | riempire un'area | filled box

see: rect, cls
text:
Un rettangolo pieno: x, y è l'angolo in alto a sinistra, w e h larghezza

rectfill(px, py, 16, 16, 0xFFD050)                   -- un blocco 16x16

== print
kind: api
name: print
title: print(testo, x, y, [c, scala]) - scrive sullo schermo
title_en: print(text, x, y, [c, scale]) - writes on the screen
ask: scrivere un testo sullo schermo | stampare una scritta | draw text | show text
ask: mostrare il punteggio | scritta grande | testo ingrandito | write a number on screen
ask: font | carattere | dimensione del testo | big text
see: rgb, log
text:
Scrive con il font 8x16 (bianco se c manca); scala da 1 a 8 lo ingrandisce
(2 = caratteri 16x32). Restituisce la x dopo l'ultimo carattere. Per
scritte ben allineate usa x multipli di 8 e y multipli di 16.
text_en:
Writes with the 8x16 font (white if c is missing); scale from 1 to 8
makes it bigger (2 = 16x32 characters). Returns the x after the last
character. For well aligned text use x multiples of 8 and y multiples
of 16.
code:
print("punti: " .. score, 8, 8, 0xFFFFFF)
print("GAME OVER", 248, 160, 0xFF4040, 2)       -- doppio
local fine = print("vite ", 8, 24)              -- continua dopo
print(lives, fine, 24, 0xFFD050)

== camera
kind: api
name: camera
title: camera([x, y]) - sposta la visuale (scorrimento)
title_en: camera([x, y]) - moves the view (scrolling)
ask: spostare la visuale | scorrimento dello schermo | scrolling | move the camera
ask: la telecamera segue il giocatore | mondo più grande dello schermo | offset del disegno
see: map, clip
text:
Da qui in poi tutto il disegno è spostato di (-x, -y): si disegna in
coordinate del mondo e camera() decide quale parte si vede. camera()
senza argomenti la azzera (per l'HUD, che sta fermo).
text_en:
From here on all drawing is moved by (-x, -y): you draw in world
coordinates and camera() decides which part is seen. camera() without
arguments resets it (for the HUD, which stays still).
code:
camera(px - SCREEN_W // 2, py - SCREEN_H // 2)  -- giocatore al centro
map(0, 0)
spr(1, px, py)
camera()                                         -- l'HUD non scorre
print("punti " .. score, 8, 8)

== clip
kind: api
name: clip
title: clip([x, y, w, h]) - limita il disegno a un rettangolo
title_en: clip([x, y, w, h]) - limits drawing to a rectangle
ask: disegnare solo in una parte dello schermo | ritagliare il disegno | clip rectangle
ask: finestra di disegno | schermo diviso | split screen | maschera rettangolare
see: camera
text:
Da qui in poi si disegna solo dentro il rettangolo; clip() senza
argomenti torna a tutto lo schermo. Utile per lo schermo diviso in due.
text_en:
From here on you draw only inside the rectangle; clip() without
arguments goes back to the whole screen. Useful for a split screen.
code:
clip(0, 0, SCREEN_W // 2, SCREEN_H)       -- meta' sinistra: giocatore 1
camera(p1.x - 160, p1.y - 180)
map(0, 0)
clip(SCREEN_W // 2, 0, SCREEN_W // 2, SCREEN_H)
camera(p2.x - 480, p2.y - 180)
map(0, 0)
clip()
camera()

== rgb
kind: api
name: rgb
title: rgb(r, g, b) - un colore dai tre canali
title_en: rgb(r, g, b) - a colour from the three channels
ask: come si scrive un colore | colori in esadecimale | rgb color | colore casuale
ask: mescolare rosso verde e blu | 0xRRGGBB | che formato hanno i colori | random color
see: cls
text:
I colori sono interi 0xRRGGBB (0xFF8000 è arancione) oppure rgb(r, g, b)
con valori 0-255. Lo schermo li riduce a 16 bit (RGB565).
text_en:
Colours are integers 0xRRGGBB (0xFF8000 is orange) or rgb(r, g, b)
with values 0-255. The screen reduces them to 16 bits (RGB565).
code:
local arancio = 0xFF8000
local c = rgb(math.random(255), math.random(255), math.random(255))
circfill(x, y, 10, c)

== screen_size
kind: api
name: SCREEN_W
title: SCREEN_W, SCREEN_H - le dimensioni dello schermo
title_en: SCREEN_W, SCREEN_H - the size of the screen
ask: quanto è grande lo schermo | larghezza dello schermo | screen width and height
ask: risoluzione | centro dello schermo | 640x360 | 320x180 | screen resolution
see: print
text:
640 e 360 (o 320 e 180 per le cartucce a bassa risoluzione, --res 320x180
o "risoluzione" nel menu dell'editor). (0, 0) è l'angolo in alto a sinistra.
text_en:
640 and 360 (or 320 and 180 for low resolution cartridges, --res 320x180

code:
local cx, cy = SCREEN_W // 2, SCREEN_H // 2    -- il centro
circfill(cx, cy, 4, 0xFFFFFF)

== font
kind: api
name: font
title: font([nome]) - il font di print: 6x12, 8x14 o 8x16
title_en: font([name]) - the font of print: 6x12, 8x14 or 8x16
ask: cambiare il font | testo più piccolo | font piccolo | change the font size
ask: scritte più piccole per avere più righe | dimensione dei caratteri | small text
text: Da qui in poi print usa quel font: "6x12" (106 colonne per 30 righe a
640x360), "8x14" o "8x16" (quello normale). Restituisce larghezza e altezza di un
carattere del font corrente.
text_en: From here on print uses that font: "6x12" (106 columns by 30 rows at
640x360), "8x14" or "8x16" (the normal one). Returns the width and height of a
character of the current font.
code:
local cw, ch = font("6x12")
print("tante righe con il font piccolo", 0, 0)
font("8x16")
