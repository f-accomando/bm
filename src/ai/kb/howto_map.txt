== map_scroll
kind: howto
title: Mappa grande che scorre con il giocatore
title_en: A big map that scrolls with the player
ask: mappa più grande dello schermo | scorrimento della mappa | scrolling map
ask: la telecamera segue il giocatore | livello che scorre | side scroller
ask: disegnare solo la parte visibile della mappa
ask: il livello scorre mentre cammino | far scorrere la mappa
keys: scorrimento, scorre, scrolling
see: camera, map, camera_smooth, lib.camera
text:
camera() sul giocatore e map() solo per le celle visibili (81x46 celle
coprono lo schermo anche a metà cella).
text_en:
camera() on the player and map() only for the visible cells (81x46 cells
cover the screen even at half a cell).
code:
local cx = math.max(0, px - SCREEN_W // 2)
local cy = math.max(0, py - SCREEN_H // 2)
camera(cx, cy)
map(cx // 8, cy // 8, cx // 8 * 8, cy // 8 * 8, 81, 46)
spr(1, px, py)
camera()

== tile_flags
kind: howto
title: Tipi di tile con i flag (muro, piattaforma, scala, pericolo)
title_en: Tile types with flags (wall, platform, ladder, danger)
ask: quali tile sono solide | tipi di tile | muri e pavimento | tile types
ask: tile che fanno male | acqua lava spine | proprietà delle tile
ask: segnare quali tile sono muri | tile flags | come uso i flag delle tile
ask: tile che bloccano il personaggio | come segno le tile solide | which tiles are walls | muro o pavimento per ogni tile
keys: tipi, flag, solide, pericolo
see: fget, fset, mflags, collide_map
text:
Ogni tile ha 8 flag: dicono che cosa è per il gioco, così il codice non
dipende dai numeri delle tile. Convenzione di bmlib: 0 solido (1), 1
piattaforma (2), 2 scala (4), 3 acqua (8), 4 fa male (16). Si danno con
mkbm.py --flags, con l'editor (tasti 0-7) o con fset.
text_en:
Each tile has 8 flags: they say what it is to the game, so the code does
not depend on the numbers of the tiles. The bmlib convention: 0 solid (1),
1 platform (2), 2 ladder (4), 3 water (8), 4 hurts (16). You set them with
mkbm.py --flags, with the editor (keys 0-7) or with fset.
code:
fset(32, 0, true)                       -- muro
fset(64, 4, true)                       -- spine: fanno male
local f = mflags(px, py, 8, 8)     -- quello che tocca lo sprite
if f & 16 ~= 0 then lives = lives - 1 end

== map_in_code
kind: howto
title: Scrivere un livello nel codice (con mset)
title_en: Writing a level in the code (with mset)
ask: livello scritto nel codice | mappa da stringhe | creare la mappa senza csv
ask: disegnare il livello con i caratteri | level from text
keys: livello, stringhe, mset
see: mset, map
text:
Ogni carattere è una tile: # muro (cella 32), o moneta (cella 5).
text_en:
Each character is a tile: # wall (cell 32), o coin (cell 5).
code:
local level = {
  "##########",
  "#o.....o.#",
  "#..####..#",
  "##########",
}
local tiles = { ["#"] = 32, o = 5 }
for y, row in ipairs(level) do
  for x = 1, #row do
    mset(x - 1, y - 1, tiles[row:sub(x, x)] or 0)
  end
end

== map_layers
kind: howto
title: Livelli della mappa: cose davanti al personaggio
title_en: Map layers: things in front of the character
ask: albero davanti al personaggio | il personaggio passa dietro | map layers
ask: mappa a più livelli | livello sopra il giocatore | draw tiles over the player
ask: tetti e chiome davanti | sfondo e primo piano della mappa | foreground layer
keys: livelli, davanti, primo, piano
see: map, mlayers, mget
text:
La mappa ha fino a 8 livelli della stessa misura. Disegna il livello di
sotto, poi gli sprite, poi quello davanti. Nel .bm: mkbm.py --map
mappa.csv --map front=davanti.csv; ogni livello si legge e scrive da sé.
text_en:
The map has up to 8 layers of the same size. Draw the layer below, then
the sprites, then the one in front. In the .bm: mkbm.py --map mappa.csv
--map front=davanti.csv; each layer is read and written on its own.
code:
map(0, 0, 0, 0, 80, 45, "main")    -- pavimento e muri
spr(1, px, py)
map(0, 0, 0, 0, 80, 45, "front")   -- chiome, archi: sopra l'eroe
if mget(cx, cy, "front") ~= 0 then hidden = true end

== map_gen
kind: howto
title: Generare una mappa a caso (grotte)
title_en: Generating a random map (caves)
ask: generare una mappa casuale | livello procedurale | random cave | dungeon generato
ask: mappa diversa ogni partita | generazione procedurale
keys: generare, procedurale, casuale
see: mset, map_in_code
text:
Riempi a caso, poi qualche passo di "automa cellulare": una cella diventa
muro se intorno ci sono tanti muri. Viene una grotta.
text_en:
Fill it at random, then a few steps of "cellular automaton": a cell
becomes a wall if there are many walls around it. You get a cave.
code:
local W, H = 80, 45
for y = 0, H - 1 do
  for x = 0, W - 1 do
    mset(x, y, math.random() < 0.45 and 32 or 0)
  end
end
for step = 1, 4 do
  for y = 1, H - 2 do
    for x = 1, W - 2 do
      local n = 0
      for j = -1, 1 do for i = -1, 1 do
        if mget(x + i, y + j) == 32 then n = n + 1 end
      end end
      mset(x, y, n >= 5 and 32 or 0)
    end
  end
end

== map_big
kind: howto
title: Disegnare una mappa grande con tile 16x16
title_en: Drawing a big map with 16x16 tiles
ask: come disegno una mappa grande con tile 16x16 | mappa grande nell'sdk | pennello 16x16
ask: how do I draw a big map with 16x16 tiles | big map in the sdk | 16x16 brush
ask: mappa 256x256 | disegnare un mondo grande | tile da 16 pixel sulla mappa
keys: grande, 16x16, mappa, big, brush, pennello
see: map_layers, map_scroll, map_in_code, map_tiled, guide.platformer
text:
Sulla pagina mappa dell'SDK (F3 due volte) z passa dal pennello 8x8 a
quello 16x16: una tile da 2 x 2 celle (n, n+1 e le due sotto sullo sheet).
m mostra tutta la mappa 256x256 in uno schermo per spostarti; con Tab, a
16x16, vedi solo le tile gia' usate nella mappa. l e L cambiano e
aggiungono livelli. Per un esempio guarda carts/yharnam/build/mkmap.py.
text_en:
On the SDK's map page (F3 twice) z switches from the 8x8 brush to the
16x16 one: a tile of 2 x 2 cells (n, n+1 and the two under them on the
sheet). m shows the whole 256x256 map on one screen so you can move; with
Tab, at 16x16, you see only the tiles already used in the map. l and L
change and add layers. For an example see carts/yharnam/build/mkmap.py.
code:
-- the game draws a 16x16 tile as 2 x 2 cells of 8x8
map(0, 0, 0, 0, 80, 45, "main")

== map_tiled
kind: howto
title: Importare una mappa di Tiled
title_en: Importing a Tiled map
ask: importare una mappa di tiled | caricare un file tmj | tiled map editor
ask: import a tiled map | load a tmj file in the sdk | tiled json to bm map
ask: usare tiled con bm | livelli di tiled nella mappa
keys: tiled, tmj, importare, import
see: map_big, map_layers, tile_flags
text:
In Tiled salva la mappa come JSON (.tmj): ortogonale, tile 8x8 o 16x16,
formato dei livelli CSV, dimensione fissa. Mettila nella cartella /docs
della scheda SD. Nell'SDK, menu (Esc) > "Import a Tiled map": scegli il
file e se aggiungere i livelli o sostituire la mappa. Una tile di Tiled e'
la tile dello sheet nella stessa colonna e riga. Le proprieta' booleane
solid, platform, ladder, water e hurt di una tile accendono i flag 0-4.
text_en:
In Tiled save the map as JSON (.tmj): orthogonal, 8x8 or 16x16 tiles,
CSV layer format, fixed size. Put it in the /docs folder of the SD card.
In the SDK, menu (Esc) > "Import a Tiled map": choose the file and
whether to add the layers or replace the map. A Tiled tile is the sheet
tile in the same column and row. The boolean properties solid, platform,
ladder, water and hurt of a tile turn on flags 0-4.
code:
-- after the import every Tiled layer is a map layer with its name
map(0, 0, 0, 0, 80, 45, "Ground")
