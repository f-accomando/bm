# How-to: tile maps and scrolling.

== map_scroll
kind: howto
title: Mappa grande che scorre con il giocatore
ask: mappa più grande dello schermo | scorrimento della mappa | scrolling map
ask: la telecamera segue il giocatore | livello che scorre | side scroller
ask: disegnare solo la parte visibile della mappa
ask: il livello scorre mentre cammino | far scorrere la mappa
keys: scorrimento, scorre, scrolling
see: camera, map, camera_smooth, lib.camera
text:
camera() sul giocatore e map() solo per le celle visibili (81x46 celle
coprono lo schermo anche a metà cella).
code:
local cx = math.max(0, px - SCREEN_W // 2)
local cy = math.max(0, py - SCREEN_H // 2)
camera(cx, cy)
map(cx // 8, cy // 8, cx // 8 * 8, cy // 8 * 8, 81, 46)
spr(1, px, py)
camera()

Ogni fotogramma la camera fa un pezzo (qui il 10%) della strada verso il

== tile_flags
kind: howto
title: Tipi di tile con i flag (muro, piattaforma, scala, pericolo)
ask: quali tile sono solide | tipi di tile | muri e pavimento | tile types
ask: tile che fanno male | acqua lava spine | proprietà delle tile
ask: segnare quali tile sono muri | tile flags | come uso i flag delle tile
ask: tile che bloccano il personaggio | come segno le tile solide | which tiles are walls | muro o pavimento per ogni tile
keys: tipi, flag, solide, pericolo
see: fget, fset, mflags, collide_map
text:
Ogni tile ha 8 flag: dicono che cosa è per il gioco, così il codice non
dipende dai numeri delle tile. Convenzione di bmlib: 0 solido (1), 1
piattaforma (2), 2 scala (4), 3 acqua (8), 4 fa male (16). Si danno con
mkbm.py --flags, con l'editor (tasti 0-7) o con fset.
code:
fset(32, 0, true)                       -- muro
fset(64, 4, true)                       -- spine: fanno male
local f = mflags(px, py, 8, 8)     -- quello che tocca lo sprite
if f & 16 ~= 0 then lives = lives - 1 end

== map_in_code
kind: howto
title: Scrivere un livello nel codice (con mset)
ask: livello scritto nel codice | mappa da stringhe | creare la mappa senza csv
ask: disegnare il livello con i caratteri | level from text
keys: livello, stringhe, mset
see: mset, map
text:
Ogni carattere è una tile: # muro (cella 32), o moneta (cella 5).
code:
local level = {
  "##########",
  "#o.....o.#",
  "#..####..#",
  "##########",
}
local tiles = { ["#"] = 32, o = 5 }
for y, row in ipairs(level) do
  for x = 1, #row do
    mset(x - 1, y - 1, tiles[row:sub(x, x)] or 0)
  end
end

== map_gen
kind: howto
title: Generare una mappa a caso (grotte)
ask: generare una mappa casuale | livello procedurale | random cave | dungeon generato
ask: mappa diversa ogni partita | generazione procedurale
keys: generare, procedurale, casuale
see: mset, map_in_code
text:
Riempi a caso, poi qualche passo di "automa cellulare": una cella diventa
muro se intorno ci sono tanti muri. Viene una grotta.
code:
local W, H = 80, 45
for y = 0, H - 1 do
  for x = 0, W - 1 do
    mset(x, y, math.random() < 0.45 and 32 or 0)
  end
end
for step = 1, 4 do
  for y = 1, H - 2 do
    for x = 1, W - 2 do
      local n = 0
      for j = -1, 1 do for i = -1, 1 do
        if mget(x + i, y + j) == 32 then n = n + 1 end
      end end
      mset(x, y, n >= 5 and 32 or 0)
    end
  end
end
