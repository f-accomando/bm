== jump_gravity
kind: howto
title: Saltare con la gravità
ask: come faccio saltare il personaggio | salto con la gravità | jump with gravity
ask: far cadere il giocatore | gravità | il personaggio vola via | fisica del salto
ask: saltare quando premo A | platform jump | caduta
keys: saltare, salto, gravita, jump
see: platformer, double_jump, btnp
text:
Una velocità verticale vy: la gravità la aumenta a ogni fotogramma, il
salto la rende negativa (verso l'alto). Si salta solo da terra.
code:
local vy, on_ground = 0, false

function _update()
  vy = vy + 0.35                      -- gravita'
  y = y + vy
  if y >= 300 then                    -- il pavimento
    y, vy, on_ground = 300, 0, true
  end
  if btnp(4) and on_ground then
    vy, on_ground = -7, false         -- il salto
  end
end

== platformer
kind: howto
title: Platform: camminare e saltare sulle tile della mappa
ask: gioco di piattaforme | platformer | camminare sulle piattaforme della mappa
ask: collisione con il pavimento della mappa | stare sopra i blocchi | super mario
ask: il personaggio cade attraverso il pavimento | collisioni del platform
keys: platform, piattaforme, mario
see: collide_map, jump_gravity
text:
Prima il movimento orizzontale e la sua collisione, poi quello verticale:
così si scivola lungo i muri. solid() dice se in un punto c'è una tile
solida (qui le celle da 32 a 63).
code:
local function solid(x, y)
  local t = mget(x // 8, y // 8)
  return t >= 32 and t < 64
end

function _update()
  local nx = px + ((btn(1) and 2 or 0) - (btn(0) and 2 or 0))
  if not solid(nx, py) and not solid(nx + 7, py)
     and not solid(nx, py + 7) and not solid(nx + 7, py + 7) then
    px = nx
  end
  vy = math.min(vy + 0.35, 6)
  local ny = py + vy
  if solid(px, ny + 7) or solid(px + 7, ny + 7) then
    py = (ny + 7) // 8 * 8 - 8       -- appoggiato sopra
    vy, on_ground = 0, true
  elseif solid(px, ny) or solid(px + 7, ny) then
    vy = 0                           -- testa contro il soffitto
  else
    py, on_ground = ny, false
  end
  if btnp(4) and on_ground then vy = -6 end
end

== collide_rect
kind: howto
title: Collisione tra due rettangoli
ask: collisione tra due rettangoli | due sprite si toccano | collision between two boxes
ask: controllare se il giocatore tocca il nemico | aabb | hitbox | sovrapposizione
ask: rilevare un urto | overlap check | collisioni tra sprite
keys: collisione, toccare, hitbox, rettangoli
see: collide_circle, bullets
text:
Due rettangoli si sovrappongono se nessuno dei due è tutto a sinistra,
destra, sopra o sotto l'altro.
code:
local function hit(a, b)
  return a.x < b.x + b.w and b.x < a.x + a.w and
         a.y < b.y + b.h and b.y < a.y + a.h
end

if hit(player, enemy) then lives = lives - 1 end

== collide_map
kind: howto
title: Collisioni con i muri della mappa
ask: collisione con i muri | non attraversare i muri | wall collision with the tile map
ask: tile solide | il personaggio passa attraverso i muri | blocchi solidi della mappa
ask: labirinto con i muri | top down collision
keys: muri, solide, attraversare
see: mget, platformer, tile_ranges
text:
Prova la nuova posizione: se uno degli angoli dello sprite finisce su una
tile solida, non muoverti. x e y separati, così si scivola lungo i muri.
code:
local function solid(x, y)
  local t = mget(x // 8, y // 8)
  return t >= 32 and t < 64
end

local function free(x, y)            -- uno sprite 8x8
  return not (solid(x, y) or solid(x + 7, y) or
              solid(x, y + 7) or solid(x + 7, y + 7))
end

if free(px + dx, py) then px = px + dx end
if free(px, py + dy) then py = py + dy end
