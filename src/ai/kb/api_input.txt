# Input: buttons, sticks, players, keyboard.

== btn
kind: api
name: btn
title: btn(i, [p]) - tasto premuto (finché lo tieni)
ask: sapere se un tasto è premuto | leggere i tasti | is a button pressed | read input
ask: tasto tenuto premuto | frecce della tastiera | pulsante del controller | gamepad
ask: quali numeri hanno i tasti | tasto A e tasto B | button numbers
see: btnp, stick, move_arrows
text:
true finché il tasto i è premuto. 0 sinistra, 1 destra, 2 su, 3 giù,
4 A, 5 B, 6 X, 7 Y, 8 Start, 9 Select. Tastiera: frecce o WASD, A =
spazio/Z/J, B = X/K, X = C/L, Y = V/I, Start = Invio. Senza p risponde
qualsiasi controller; con p (1-4) solo quello del giocatore p.
code:
if btn(0) then x = x - 2 end     -- sinistra
if btn(1) then x = x + 2 end     -- destra
if btn(4) then sparo() end       -- A tenuto: fuoco continuo

== btnp
kind: api
name: btnp
title: btnp(i, [p]) - tasto appena premuto (una volta sola)
ask: tasto premuto una volta sola | solo quando premo il tasto | button just pressed
ask: saltare una volta per pressione | il tasto ripete troppo | press once
ask: scegliere nel menu con le frecce | evento di pressione
see: btn
text:
true solo nel fotogramma in cui il tasto viene premuto: per saltare, per
sparare un colpo per pressione, per i menu. btn() invece resta vero finché
il tasto è giù.
code:
if btnp(4) and on_ground then
  vy = -6                          -- un salto per pressione
end
if btnp(2) then choice = choice - 1 end   -- menu: su

== players
kind: api
name: players
title: players() - quanti giocatori hanno un controller
ask: quanti giocatori ci sono | numero di controller collegati | how many players
ask: quanti pad sono connessi | gioco a più giocatori | multiplayer count
see: btn, two_players
text:
Quanti giocatori hanno un controller (almeno 1) e, come secondo valore,
quali (bit n = giocatore n+1).
code:
local n, mask = players()
print(n .. " giocatori", 8, 8)
if mask & 2 ~= 0 then print("c'e' il giocatore 2", 8, 24) end

== stick
kind: api
name: stick
title: stick([p, n]) - la levetta analogica
ask: leggere la levetta analogica | joystick analogico | analog stick | levetta del pad
ask: movimento analogico | quanto è spinta la levetta | thumbstick
ask: levetta destra per mirare | right stick aim | mirare con il pad
see: btn, move_stick
text:
x, y tra -1 e 1 della levetta sinistra del giocatore p (x a destra, y in
basso), con zona morta. Con la tastiera vale la croce (8 direzioni).
stick(p, 1) è la levetta destra (mira degli sparatutto): 0, 0 senza.
code:
local sx, sy = stick(1)
x = x + sx * 3
y = y + sy * 3

== mouse
kind: api
name: mouse
title: mouse([on]) - il puntatore del mouse
ask: usare il mouse | posizione del mouse | dove punta il mouse | read the mouse
ask: cursore del mouse nel gioco | mouse position | puntatore sullo schermo
ask: cliccare con il mouse | rotellina del mouse | mouse wheel | pointer
keys: mouse, puntatore, cursore, pointer
see: mousep, btn, stick
text:
Una cartuccia ha il puntatore solo se lo chiede: mouse(true) una volta
(mouse(true, false) senza la freccia della console). Poi mouse() dà x, y
in pixel dello schermo, i tasti (1 sinistro, 2 destro, 4 centrale), gli
scatti della rotellina e se si vede; nil se non c'è niente che lo muova.
Lo muove solo un mouse USB o Bluetooth (un controller no).
code:
function _init() mouse(true) end
function _update()
  local mx, my, mb = mouse()
  if mx and mb & 1 ~= 0 then x, y = mx, my end   -- trascina
end

== mousep
kind: api
name: mousep
title: mousep([i]) - un clic del mouse (una volta sola)
ask: clic del mouse | ho cliccato | mouse click | click once | il giocatore ha cliccato
ask: tasto destro del mouse | right click | premere il tasto del mouse | detect a click
ask: did the user click | cliccare su un pulsante | button clicked with the mouse
keys: clic, click, mouse
see: mouse, btnp
text:
true solo nel fotogramma in cui il tasto i del mouse viene premuto: 0
sinistro (il default), 1 destro, 2 centrale. Serve mouse(true) prima.
code:
local mx, my = mouse()
if mx and mousep() then
  sfx(0)                           -- un clic: un suono
end

== keyp
kind: api
name: keyp
title: keyp() - il prossimo tasto scritto (tastiera)
ask: leggere la tastiera come testo | scrivere con la tastiera | get typed key
ask: inserire il nome del giocatore | campo di testo | text input | keyboard typing
ask: tasti funzione | f1 f2 | ctrl s | tasto esc
see: keyheld, name_input
text:
Il prossimo tasto scritto: un carattere ("a", "\n" Invio, "\b"
Backspace), un nome ("up", "down", "left", "right", "pgup", "del", "esc",
"f1"..."f10"), "^s" per Ctrl+S e "^S" per Ctrl+Shift+S (anche "^i" e "^m",
non Tab e Invio); nil se nessuno. Dalla prima chiamata la
tastiera scrive e non fa più da gamepad, ed Esc non chiude il gioco.
code:
local k = keyp()
while k do
  if k == "\b" then name = name:sub(1, -2)
  elseif #k == 1 then name = name .. k end
  k = keyp()
end

== keyheld
kind: api
name: keyheld
title: keyheld(nome) - un tasto della tastiera USB tenuto premuto
ask: tasto della tastiera tenuto premuto | f12 tenuto | key held down | tenere premuto tab
see: keyp
text:
true finché il tasto è tenuto sulla tastiera USB: "f1".."f12", "tab",
"space", "enter", "esc". L'editor lo usa per l'aiuto su F12.
code:
if keyheld("f12") then
  print("aiuto: frecce muovono, spazio salta", 8, 8)
end

== controller
kind: api
name: controller
title: controller([p]) - con che cosa gioca il giocatore p
ask: che controller ha il giocatore | il giocatore usa la tastiera o il pad | ds4 o xbox
ask: which controller does the player use | nomi dei tasti del pad | colore del giocatore
keys: controller, ds4, xbox, tastiera
see: keymap, players, lib.pads
text:
Una tabella: kind ("keyboard", "ds4", "xbox", "pad", "builtin",
"none"), layout (come si chiamano i tasti), bluetooth, ok e back (i tasti
del sì e dell'indietro), color (il colore del giocatore, quello della
luce del pad).
code:
local c = controller(2)
if c.kind ~= "none" then print("P2: " .. c.kind, 8, 8, c.color) end

== keymap
kind: api
name: keymap
title: keymap(t) - le azioni del gioco sui tasti
ask: azioni del gioco | tasti personalizzabili | rimappare i tasti | remap buttons
ask: saltare con un nome invece del numero | btn con il nome dell'azione | key bindings
keys: keymap, azioni, rimappare
see: btn, controller
text:
keymap({ jump = "a", fire = {"x", "r1"} }) dà un nome alle azioni; poi
btn("jump", p), btnp("fire") e prompt("jump", x, y). Il gioco cambia i
tasti chiamandola di nuovo (e li tiene con save()).
code:
keymap({ jump = "a", fire = { "x", "r1" }, pause = "start" })
if btnp("jump") then vy = -5 end

== online
kind: api
name: online
title: online(on, [nota]) - la partita è in rete: PS non sospende
ask: partita in rete e tasto ps | non sospendere il gioco online | uscire dalla partita online
ask: online true | leave the online match | _leave
keys: online, sospendere, leave
see: bmnet, net.open, callbacks
text:
Con online(true) PS non sospende il gioco (gli altri giocano): chiede al
giocatore se esce; sì chiama _leave() e chiude la cartuccia. bmnet lo
accende da sé quando la partita comincia.
code:
function _leave()
  net.close()                         -- avvisa gli altri
end
