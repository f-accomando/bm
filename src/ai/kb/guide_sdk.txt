== guide.sdk_start
kind: guide
title: Guida: cominciare un gioco con l'SDK
title_en: Guide: starting a game with the SDK
ask: come comincio un gioco con l'sdk | primo gioco con bm sdk | da dove parto per fare un gioco
ask: how do i start a game with the sdk | make my first game | nuovo progetto nell'sdk
ask: voglio creare un videogioco | create a new game project | come si crea un gioco su bm
ask: i passi per fare un gioco | guida per principianti | beginner guide
keys: sdk, cominciare, progetto, guida
see: guide.sdk_pages, guide.platformer, guide.3d_first
text:
1. Nell'SDK, Ctrl+N: scegli un modello (Platform 2D, Top-down 2D, Shooter
2D, Versus 2D per due giocatori, Online 2D in rete, 3D scene, 3D with
models). Arriva con codice, sprite e mappa pronti.

2. F5 prova subito il gioco; Esc (o Ctrl+Esc) torna all'SDK.

3. F2 il codice: cambia velocità, colori, testi. F3 gli sprite e la
mappa, F4 i modelli 3D.

4. Esc > Save as dà il nome al file (8.3, in /carts); poi Ctrl+S salva.

5. F1 è la pagina del progetto: da lì 1-6 aprono il progetto negli altri
programmi della suite. F1 di nuovo: il dev kit (fps, RAM, token).
text_en:
1. In the SDK, Ctrl+N: choose a template (Platform 2D, Top-down 2D, Shooter
2D, Versus 2D for two players, Online 2D over the network, 3D scene, 3D
with models). It comes with code, sprites and map ready.

2. F5 tries the game right away; Esc (or Ctrl+Esc) goes back to the SDK.

3. F2 the code: change speeds, colours, texts. F3 the sprites and the
map, F4 the 3D models.

4. Esc > Save as gives the file its name (8.3, in /carts); then Ctrl+S saves.

5. F1 is the project page: from there 1-6 open the project in the other
programs of the suite. F1 again: the dev kit (fps, RAM, tokens).
code:
-- il gioco minimo: _init una volta, _update e _draw a ogni fotogramma
function _init()
  x, y = SCREEN_W / 2, SCREEN_H / 2
end

function _update()
  if btn(0) then x = x - 2 end
  if btn(1) then x = x + 2 end
end

function _draw()
  cls(0x101828)
  circfill(x, y, 10, 0xFFD050)
end

== guide.platformer
kind: guide
title: Guida: un platform 2D passo passo
title_en: Guide: a 2D platformer step by step
ask: come faccio un platform | fare un gioco di piattaforme | platform game step by step
ask: gioco tipo mario | make a platformer with the sdk | personaggio che salta sulle piattaforme
ask: guida platform 2d | un gioco a scorrimento con i salti | side scroller
keys: platform, piattaforme, mario
see: jump_gravity, lib.step, tile_flags, lib.camera, guide.map
text:
1. Ctrl+N > Platform 2D: lo sprite 1 è l'eroe, il 2 il terreno (flag 0:
solido), il 6 le assi (flag 1: piattaforma, si sale da sotto).

2. F3: i tasti 0-7 accendono i flag della tessera scelta; F3 di nuovo,
la mappa: disegna altre piattaforme con la tessera 2 o 6.

3. Nel codice lib.step(hero) fa gravità e mappa (bmlib): legge i flag,
dice hero.ground; il salto mette vy negativa solo a terra.

4. La camera di bmlib segue l'eroe: cam:apply() prima della mappa,
camera() prima del testo.

5. Poi: nemici (guida dei nemici), monete (pickup_tiles), suoni (sfx).
text_en:
1. Ctrl+N > Platform 2D: sprite 1 is the hero, 2 the ground (flag 0:
solid), 6 the planks (flag 1: platform, you go up through it from below).

2. F3: keys 0-7 turn on the flags of the chosen tile; F3 again,
the map: draw more platforms with tile 2 or 6.

3. In the code lib.step(hero) does gravity and the map (bmlib): it reads
the flags and sets hero.ground; the jump makes vy negative only on the
ground.

4. The bmlib camera follows the hero: cam:apply() before the map,
camera() before the text.

5. Then: enemies (the enemies guide), coins (pickup_tiles), sounds (sfx).
code:
local lib = require "bmlib"
local hero = { x = 64, y = 40, w = 8, h = 8 }
function _update()
  hero.vx = btn(0) and -2 or btn(1) and 2 or 0
  if hero.ground and btnp(4) then hero.vy = -5 end
  lib.step(hero)                      -- gravita', flag delle tessere
end

kind: guide
title: Guida: un gioco in rete per più console
title_en: Guide: a network game for several consoles
ask: gioco in rete | giocare online | multiplayer in rete | online game

ask: guida online | lobby e partita | lockstep | giocare su internet

text:
1. Ctrl+N > Online 2D: ogni console muove il suo quadrato. A ospita una
partita o entra in una trovata; chi ospita la comincia con Start.

2. bmnet (require "bmnet"): net.open, net.host o net.join, net.update a
ogni fotogramma (dà gli eventi: join, start, msg, leave, lost).

3. Lockstep: ogni console fa girare tutto il gioco, viaggiano solo gli
input. net.input(net.pad(1)), poi i fotogrammi pronti in net.frames().

4. Numeri a caso solo da lib.rng(seme della partita), mai math.random.

5. Su internet: un relay (tools/overbit_relay.py) e l'opzione relay.
text_en:
1. Ctrl+N > Online 2D: each console moves its own square. A hosts a
match or joins one it found; the host starts it with Start.

2. bmnet (require "bmnet"): net.open, net.host or net.join, net.update
every frame (it gives the events: join, start, msg, leave, lost).

3. Lockstep: every console runs the whole game, only the inputs travel.
net.input(net.pad(1)), then the frames that are ready in net.frames().

4. Random numbers only from lib.rng(the match's seed), never math.random.

5. Over the internet: a relay (tools/overbit_relay.py) and the relay
option.
code:
local net = require "bmnet"
net.open({ game = "MYG1" })
function _update()
  for _, e in ipairs(net.update()) do end   -- gli eventi
  if net.state == "playing" then
    net.input(net.pad(1))
    for _, inputs in net.frames() do step(inputs) end
  end
end

== guide.puzzle
kind: guide
title: Guida: un gioco a griglia (puzzle)
title_en: Guide: a grid game (puzzle)
ask: gioco a griglia | puzzle game | tris | sokoban | gioco con le caselle
ask: come faccio un puzzle | match three | griglia di celle | grid based game
ask: guida gioco a caselle | memory game | board game
keys: griglia, puzzle, caselle
see: grid_move, lua_tables
text:
1. Parti da Empty 2D (Ctrl+N). La griglia è una tabella di righe:
grid[r][c].

2. Un cursore (r, c) si muove con btnp, A cambia la casella.

3. _draw disegna ogni casella come rettangolo (o sprite) a c*S, r*S.

4. Dopo ogni mossa controlla la vittoria scorrendo la griglia.
text_en:
1. Start from Empty 2D (Ctrl+N). The grid is a table of rows:
grid[r][c].

2. A cursor (r, c) moves with btnp, A changes the cell.

3. _draw draws each cell as a rectangle (or a sprite) at c*S, r*S.

4. After each move check for a win by going through the grid.
code:
local N, S = 6, 32
local grid = {}
for r = 1, N do
  grid[r] = {}
  for c = 1, N do grid[r][c] = 0 end
end
local function draw_grid()
  for r = 1, N do
    for c = 1, N do
      local on = grid[r][c] == 1
      rectfill(c * S, r * S, S - 2, S - 2, on and 0xFFC050 or 0x303850)
    end
  end
end
