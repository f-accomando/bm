== lua_tables
kind: howto
title: Lua: liste e tabelle
title_en: Lua: lists and tables
ask: come si usa una tabella | creare una lista | aggiungere un elemento alla lista
ask: lua table | array in lua | togliere un elemento | lunghezza della lista
ask: table.insert e table.remove | dizionario | chiave e valore
keys: tabella, lista, array, table
see: lua_loops, enemies_list
text:
Una tabella fa da lista (indici da 1) e da dizionario (chiavi). #t è la
lunghezza della lista.
text_en:
A table works as a list (indexes from 1) and as a dictionary (keys). The
length of the list is #t.
code:
local list = { 10, 20, 30 }
list[#list + 1] = 40           -- aggiungi in fondo
table.insert(list, 1, 5)       -- in testa
table.remove(list, 2)          -- togli il secondo
local p = { x = 10, y = 20 }   -- dizionario
p.hp = 3
log(#list, p.x, p["y"])

kind: howto
title: Lua: cicli for, while, ipairs, pairs

ask: ipairs e pairs | while | ciclo all'indietro | repeat until | iterate
keys: ciclo, for, while, ripetere
see: lua_tables
text:
for numerico (anche all'indietro), ipairs per le liste, pairs per tutte
le chiavi, while finché vale una condizione.
text_en:
Numeric for (backwards too), ipairs for lists, pairs for all the keys,

== lua_local
kind: howto
title: Lua: variabili locali e globali
title_en: Lua: local and global variables
ask: local o globale | variabile locale | quando usare local | global variable
ask: la variabile è nil in un'altra funzione | scope delle variabili
keys: local, globale, variabile
see: lua_functions, err_index_nil
text:
Senza local una variabile è globale: la vedono tutte le funzioni. Con
local esiste solo nel blocco (funzione, if, for). Le local sono più

text_en:

== lua_objects
kind: howto
title: Lua: oggetti con metodi (classi)
title_en: Lua: objects with methods (classes)
ask: classi in lua | oggetti con metodi | programmazione a oggetti | metatable
ask: creare tanti nemici dello stesso tipo | object oriented | self
keys: classe, oggetto, metodo, self
see: enemies_list
text:
Una tabella fa da classe: setmetatable dà ai nuovi oggetti i suoi metodi;
con i due punti (e:update()) il metodo riceve l'oggetto come self.
text_en:
A table works as a class: setmetatable gives new objects its methods;
with the colon (e:update()) the method gets the object as self.
code:
local Enemy = {}
Enemy.__index = Enemy

function Enemy.new(x, y)
  return setmetatable({ x = x, y = y, hp = 3 }, Enemy)
end

function Enemy:update()
  self.x = self.x + 1
end

local e = Enemy.new(10, 20)
e:update()

== lua_coroutines
kind: howto
title: Lua: sequenze con le coroutine (scene, cutscene)
title_en: Lua: sequences with coroutines (scenes, cutscenes)
ask: sequenza di azioni nel tempo | cutscene | aspettare dentro una funzione
ask: coroutine | script di una scena | fare una cosa dopo l'altra | wait
ask: eventi in sequenza con attese | prima una cosa poi un'altra con una pausa
keys: coroutine, sequenza, cutscene
see: timer
text:
Una coroutine si ferma con yield e riparte al fotogramma dopo: si scrive
una sequenza come una storia, con le attese dentro.
text_en:
A coroutine stops with yield and starts again on the next frame: you
write a sequence like a story, with the waits inside.
code:
local function wait(frames)
  for i = 1, frames do coroutine.yield() end
end

local scene = coroutine.create(function()
  say = "Benvenuto!"; wait(120)
  say = "Trova la chiave."; wait(120)
  say = nil
end)

function _update()
  if coroutine.status(scene) ~= "dead" then coroutine.resume(scene) end
end
