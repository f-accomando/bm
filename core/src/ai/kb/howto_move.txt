# How-to: moving things.

== move_arrows
kind: howto
title: Muovere un personaggio con le frecce
title_en: Moving a character with the arrow keys
ask: come muovo il personaggio con le frecce | muovere uno sprite con i tasti
ask: spostare il giocatore | move the player with the arrow keys | movimento del personaggio
ask: controllare il personaggio | far camminare l'omino | walk with the keyboard
keys: muovere, frecce, move
see: spr, move_8dir, clamp_screen
text:
btn(0..3) sono sinistra, destra, su, giù (frecce, WASD o la croce del
pad): finché il tasto è premuto si cambia la posizione.
text_en:
btn(0..3) are left, right, up, down (arrows, WASD or the cross of the
pad): while the key is held, the position changes.
code:
local x, y, speed = 320, 180, 2

function _update()
  if btn(0) then x = x - speed end   -- sinistra
  if btn(1) then x = x + speed end   -- destra
  if btn(2) then y = y - speed end   -- su
  if btn(3) then y = y + speed end   -- giu
end

function _draw()
  cls(0)
  spr(1, x, y)
end

== move_8dir
kind: howto
title: Movimento in 8 direzioni alla stessa velocità
title_en: Moving in 8 directions at the same speed
ask: in diagonale va più veloce | movimento diagonale | 8 directions movement
ask: normalizzare la velocità | camminare in diagonale | top down movement
ask: troppo veloce in diagonale | corre di più in diagonale
keys: diagonale, normalizzare
see: move_arrows
text:
In diagonale si sommano due spostamenti: dividi per la radice di 2 (0.707)
così la velocità resta la stessa.
text_en:
On a diagonal two moves add up: divide by the square root of 2 (0.707) so
the speed stays the same.
code:
local dx, dy = 0, 0
if btn(0) then dx = dx - 1 end
if btn(1) then dx = dx + 1 end
if btn(2) then dy = dy - 1 end
if btn(3) then dy = dy + 1 end
if dx ~= 0 and dy ~= 0 then dx, dy = dx * 0.707, dy * 0.707 end
x, y = x + dx * speed, y + dy * speed

== chase
kind: howto
title: Un nemico che insegue il giocatore
title_en: An enemy that chases the player
ask: nemico che insegue il giocatore | seguire il giocatore | chase the player
ask: inseguimento | andare verso un punto | follow target | homing
ask: nemico che mi insegue | mi viene addosso | inseguitore
keys: inseguire, seguire, inseguimento
see: enemies_list, distance
text:
Calcola la direzione verso il giocatore, normalizzala e fai un passo.
text_en:
Work out the direction to the player, normalize it and take a step.
code:
local dx, dy = px - e.x, py - e.y
local d = math.sqrt(dx * dx + dy * dy)
if d > 1 then
  e.x = e.x + dx / d * e.speed
  e.y = e.y + dy / d * e.speed
end
