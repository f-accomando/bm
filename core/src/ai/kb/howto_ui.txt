== center_text
kind: howto
title: Scrivere un testo centrato
title_en: Writing centred text
ask: centrare un testo | scritta al centro dello schermo | center text
ask: allineare il testo al centro | titolo centrato
ask: scritta in mezzo allo schermo | testo nel mezzo
keys: centrare, centrato
see: print
text:
Ogni carattere è largo 8 pixel (per la scala): la x è metà schermo meno
metà della larghezza del testo.
text_en:
Each character is 8 pixels wide (times the scale): x is half the screen
minus half the width of the text.
code:
local function center(s, y, c, scale)
  scale = scale or 1
  print(s, (SCREEN_W - #s * 8 * scale) // 2, y, c, scale)
end
center("GAME OVER", 160, 0xFF4040, 2)

== title_menu
kind: howto
title: Menu con le voci da scegliere
title_en: A menu with items to choose from
ask: menu del titolo | scegliere una voce con le frecce | menu with options
ask: menu iniziale con gioca e opzioni | cursore nel menu | select menu item
keys: menu, voci, scegliere
see: game_states, btnp, lib.menu
text:
Un indice della voce scelta: su e giù lo cambiano, A conferma.
text_en:
An index of the chosen item: up and down change it, A confirms.
code:
local items, sel = { "Gioca", "Opzioni", "Esci" }, 1

function menu_update()
  if btnp(2) then sel = (sel - 2) % #items + 1 end
  if btnp(3) then sel = sel % #items + 1 end
  if btnp(4) then return items[sel] end
end

function menu_draw()
  for i, s in ipairs(items) do
    print((i == sel and "> " or "  ") .. s, 256, 144 + i * 16,
          i == sel and 0xFFD050 or 0xFFFFFF)
  end
end

== dialog_box
kind: howto
title: Finestra di dialogo con il testo che appare a poco a poco
title_en: Dialogue box with text that appears little by little
ask: finestra di dialogo | il personaggio parla | dialog box | testo che appare lettera per lettera
ask: fumetto con il testo | typewriter text | dialoghi rpg
keys: dialogo, parla, fumetto
see: print
text:
Un riquadro in basso e una parte del testo che cresce a ogni fotogramma.
text_en:
A box at the bottom and a part of the text that grows every frame.
code:
local msg, shown = "Ciao, viaggiatore! La grotta e' a nord.", 0

function dialog_draw()
  shown = math.min(#msg, shown + 0.5)
  rectfill(16, 272, 608, 72, 0x101020)
  rect(16, 272, 608, 72, 0xFFFFFF)
  print(msg:sub(1, math.floor(shown)), 32, 288, 0xFFFFFF)
end

== name_input
kind: howto
title: Scrivere il nome del giocatore
title_en: Typing the player's name
ask: inserire il nome | campo di testo | scrivere il nome per la classifica | text input
ask: tastiera per il nome | entry of initials
keys: nome, scrivere, testo
see: keyp
text:
keyp() dà i tasti scritti; Backspace cancella, Invio conferma.
text_en:
keyp() gives the keys typed; Backspace deletes, Enter confirms.
code:
name = name or ""
local k = keyp()
while k do
  if k == "\b" then name = name:sub(1, -2)
  elseif k == "\n" then done = true
  elseif #k == 1 and #name < 10 then name = name .. k end
  k = keyp()
end
print("nome: " .. name .. "_", 200, 160)

== fade
kind: howto
title: Dissolvenza tra due schermate
title_en: Fading between two screens
ask: dissolvenza | fade out | schermo che diventa nero | transizione tra livelli
ask: fade in | sfumare al nero
keys: dissolvenza, fade, transizione
see: game_states
text:
Lo schermo è a 16 bit e non c'è trasparenza: una tendina nera che si
chiude a righe fa da transizione.
text_en:
The screen is 16-bit and there is no transparency: a black curtain that
closes row by row works as the transition.
code:
-- fade da 0 a 1
local h = math.floor(SCREEN_H / 2 * fade)
rectfill(0, 0, SCREEN_W, h, 0)
rectfill(0, SCREEN_H - h, SCREEN_W, h, 0)
