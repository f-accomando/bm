# How-to: jumping, gravity, collisions.

== jump_gravity
kind: howto
title: Saltare con la gravità
title_en: Jumping with gravity
ask: come faccio saltare il personaggio | salto con la gravità | jump with gravity
ask: far cadere il giocatore | gravità | il personaggio vola via | fisica del salto
ask: saltare quando premo A | platform jump | caduta
keys: saltare, salto, gravita, jump
see: platformer, double_jump, btnp
text:
Una velocità verticale vy: la gravità la aumenta a ogni fotogramma, il
salto la rende negativa (verso l'alto). Si salta solo da terra.
text_en:
A vertical speed vy: gravity increases it every frame, the jump makes it
negative (upwards). You can jump only from the ground.
code:
local vy, on_ground = 0, false

function _update()
  vy = vy + 0.35                      -- gravita'
  y = y + vy
  if y >= 300 then                    -- il pavimento
    y, vy, on_ground = 300, 0, true
  end
  if btnp(4) and on_ground then
    vy, on_ground = -7, false         -- il salto
  end
end

== platformer
kind: howto
title: Platform: camminare e saltare sulle tile della mappa
title_en: Platformer: walking and jumping on the tiles of the map
ask: gioco di piattaforme | platformer | camminare sulle piattaforme della mappa
ask: collisione con il pavimento della mappa | stare sopra i blocchi | super mario
ask: il personaggio cade attraverso il pavimento | collisioni del platform
keys: platform, piattaforme, mario
see: collide_map, jump_gravity, lib.step
text:
Prima il movimento orizzontale e la sua collisione, poi quello verticale:
così si scivola lungo i muri. solid() dice se in un punto c'è una tile
solida (con il flag 0). Più corto: lib.step di bmlib fa gravità, muri e
piattaforme.
text_en:
First the horizontal movement and its collision, then the vertical one: so
you slide along the walls. solid() says whether there is a solid tile at a
point (with flag 0). Shorter: lib.step of bmlib does gravity, walls and
platforms.
code:
local function solid(x, y)
  return fget(mget(x // 8, y // 8), 0)
end

function _update()
  local nx = px + ((btn(1) and 2 or 0) - (btn(0) and 2 or 0))
  if not solid(nx, py) and not solid(nx + 7, py)
     and not solid(nx, py + 7) and not solid(nx + 7, py + 7) then
    px = nx
  end
  vy = math.min(vy + 0.35, 6)
  local ny = py + vy
  if solid(px, ny + 7) or solid(px + 7, ny + 7) then
    py = (ny + 7) // 8 * 8 - 8       -- appoggiato sopra
    vy, on_ground = 0, true
  elseif solid(px, ny) or solid(px + 7, ny) then
    vy = 0                           -- testa contro il soffitto
  else
    py, on_ground = ny, false
  end
  if btnp(4) and on_ground then vy = -6 end
end

== collide_rect
kind: howto
title: Collisione tra due rettangoli
title_en: Collision between two rectangles
ask: collisione tra due rettangoli | due sprite si toccano | collision between two boxes
ask: controllare se il giocatore tocca il nemico | aabb | hitbox | sovrapposizione
ask: rilevare un urto | overlap check | collisioni tra sprite
keys: collisione, toccare, hitbox, rettangoli
see: collide_circle, bullets, lib.overlap
text:
Due rettangoli si sovrappongono se nessuno dei due è tutto a sinistra,
destra, sopra o sotto l'altro.
text_en:
Two rectangles overlap if neither of them is entirely to the left, right,
above or below the other.
code:
local function hit(a, b)
  return a.x < b.x + b.w and b.x < a.x + a.w and
         a.y < b.y + b.h and b.y < a.y + a.h
end

if hit(player, enemy) then lives = lives - 1 end

== collide_circle
kind: howto
title: Collisione tra due cerchi
title_en: Collision between two circles
ask: collisione tra cerchi | palle che si toccano | circle collision | raggio di collisione
ask: collisione rotonda | distanza minore della somma dei raggi
ask: two circles collide | circles overlap | sfere che si toccano
keys: cerchi, raggio
see: collide_rect, distance, lib.overlap
text:
Si toccano se la distanza tra i centri è minore della somma dei raggi
(confronta i quadrati: niente radice).
text_en:
They touch if the distance between the centres is less than the sum of the
radii (compare the squares: no square root).
code:
local dx, dy = a.x - b.x, a.y - b.y
local r = a.r + b.r
if dx * dx + dy * dy < r * r then
  log("colpito")
end

== point_in_rect
kind: howto
title: Un punto dentro un rettangolo
title_en: A point inside a rectangle
ask: punto dentro un rettangolo | il cursore è sopra il pulsante | point in rectangle
ask: cliccare su un bottone | il colpo è dentro il bersaglio
keys: punto, dentro
see: collide_rect, lib.overlap
text:
Il punto è dentro se sta tra i bordi sinistro e destro e tra quelli sopra
e sotto.
text_en:
The point is inside if it lies between the left and right edges and
between the top and bottom ones.
code:
local function inside(px, py, r)
  return px >= r.x and px < r.x + r.w and py >= r.y and py < r.y + r.h
end

== collide_map
kind: howto
title: Collisioni con i muri della mappa
title_en: Collisions with the walls of the map
ask: collisione con i muri | non attraversare i muri | wall collision with the tile map
ask: tile solide | il personaggio passa attraverso i muri | blocchi solidi della mappa
ask: labirinto con i muri | top down collision
keys: muri, solide, attraversare
see: mflags, platformer, tile_flags, lib.move
text:
Prova la nuova posizione: se lo sprite tocca una tile solida (flag 0) non
muoverti. x e y separati, così si scivola lungo i muri. mflags guarda
tutte le tile sotto il rettangolo in una chiamata; lib.move di bmlib fa
lo stesso e accosta lo sprite al muro.
text_en:
Try the new position: if the sprite touches a solid tile (flag 0), do not
move. x and y separately, so you slide along the walls. mflags looks at
all the tiles under the rectangle in one call; lib.move of bmlib does the
same and brings the sprite right up to the wall.
code:
local function free(x, y)            -- uno sprite 8x8
  return mflags(x, y, 8, 8) & 1 == 0
end

if free(px + dx, py) then px = px + dx end
if free(px, py + dy) then py = py + dy end

== pong_ball
kind: howto
title: Pallina e racchetta (come Pong o Arkanoid)
title_en: Ball and paddle (like Pong or Arkanoid)
ask: pallina che rimbalza sulla racchetta | pong | arkanoid | breakout | paddle
ask: rimbalzo sulla racchetta con angolo
keys: racchetta, pong, pallina
see: bounce_walls, collide_rect
text:
Se la palla tocca la racchetta, torna su; l'angolo dipende da dove l'ha
presa.
text_en:
If the ball touches the paddle it goes back up; the angle depends on where
the paddle caught it.
code:
if by + r >= pad.y and bx > pad.x and bx < pad.x + pad.w and vy > 0 then
  vy = -vy
  vx = (bx - (pad.x + pad.w / 2)) / (pad.w / 2) * 4
  note(0, 660, 40, SQUARE, 90)
end
