# The `.b16` Profile (Milestone M42)

This document tracks the architecture, sandbox rules and progress of the **`.b16`** format and runtime profile for the **bm** console.

Spec reference: [`docs/B16.md`](../B16.md) §0.

---

## 1. Project Goal and Philosophy

The `.b16` profile defines a resource-constrained environment (inspired by the PICO-8 philosophy but with 16-bit power), guaranteeing **perfectly identical and reproducible behavior on Raspberry Pi Zero W and PowKiddy RGB30**:
- **Same cartridge container**: dedicated profile flag in the `BMCART` header (`BM_FLAG_B16 = 2`).
- **Fixed resolution**: square **360×360** (or native 720×720 on RGB30).
- **Color palette**: 256 indexed colors (`SHEET8`).
- **Memory budget**:
  - Lua heap: maximum **4 MiB**.
  - Graphics banks: **1024×1024** pixels.
  - Persistent save: maximum **64 KiB**.
  - Maximum cartridge file size: **8 MiB**.
  - No arbitrary token limit.
- **Audio**: 8 polyphonic voices.
- **CPU budget**: cycle accounting at 60 fps; if the code exceeds the allowed budget, the engine automatically and deterministically scales down to 30 fps.
- **Controls**: SNES-style layout (d-pad + A, B, X, Y, L1, R1, Start, Select).
- **Strict sandbox**: no direct file system access (save slots only); deterministic pseudorandom generator seeded with `rnd()`.

## 2. Development Phases & M42 Roadmap

| Step | Description | Status |
|---|---|---|
| **1. Header & Tooling** | Profile flag in the `BMCART` header, `mkbm.py --b16` option, validation on read and packaging; the Pi menu shows both `.bm` and `.b16`, while the RGB30 shows only `.b16`. | **Done** |
| **2. Runtime Sandbox** | Runtime limit enforcement: fixed 360×360 screen, 256-color palette, memory isolation and limited graphics banks. | In progress |
| **3. Deterministic CPU Budget** | Measuring the cost of instructions and draw calls on the Pi; automatic 60 → 30 fps transition with load percentage shown in the SDK Dev Kit. | To do |
| **4. SDK Support** | `BM_FLAG_B16 = 2`, `bm_build_b16` in `project.c` with 8 MiB limit check and `360x360` resolution; `Ctrl+B` in the SDK for native `.b16` build when the target is `.b16`; `Ctrl+Shift+B` for *Export .b16*. On the RGB30, the export automatically copies to `/bm/` for immediate viewing in Games. | **Done** |
| **5. Reference Cartridge Porting** | Full port of *Yharnam* to `.b16` (360×360, banked sheet), followed by *Overbit* (M41). | To do |

---

## 3. Completion Criterion ("Done when")

Milestone M42 is considered complete when:
1. *Yharnam* in `.b16` format runs perfectly indistinguishably on the Raspberry Pi Zero W and the PowKiddy RGB30 inside the sandbox.
2. In compute-heavy scenes, the CPU auto-throttle drops the frame rate from 60 to 30 fps at exactly the same points and with the same load percentage on both platforms.
