# bm3D techniques of the V3D and Mali drivers: reference list
#
# One line a technique: VERSION | TARGET | DATE | NAME | KEY | WHAT IT DOES
#   VERSION  the bm3D version that added it (docs/DRIVERS.md has the full history).
#   TARGET   ARM (r3d, the CPU), V3D (the Pi Zero W GPU), ARM+V3D (both), Mali (the RGB30 GPU).
#   KEY      the config.txt key that turns it on or off, with its default. "-" : no key.
# The lines "[Title]" start a group. Lines that start with "#" are notes.
#
# The shell screen System > bm3D shows this list. core/src/kernel/bm3d_tech.c is made from
# it: after a change here, run  python core/scripts/bm3d_tech.py  and commit both files.
# The Mali group (RGB30, Mali-G52) is at the end; details: docs/progress/graphics-mali.md.
