## Descrizione

Pico has a skeleton and five moves; now he needs somewhere to run. In this episode of Tropic Trail, a 3D platformer built only with the tools
inside the bm console, we lay out the whole trail in the map editor of bm SDK: a floor with two holes, a step, a low wall, rows of apples,
wooden crates, lanterns, and the start and the goal.

You will see: the map page with four layers (floor, height, walls, objects), the path tool, the big 16x16 brush, apples, crates and lanterns
laid in one step, undo, the 3D preview that uses the same code as the game, and saving and building the cartridge.

Tropic Trail is a series of 8 videos. Each one teaches one editor of the bm console and takes a step towards the same finished game.
Next video: bm Sound, six soft effects and a jungle song.

bm: https://github.com/f-accomando/bm
