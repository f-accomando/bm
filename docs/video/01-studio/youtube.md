## Descrizione

Tropic Trail is a 3D platformer built only with the tools inside the bm console. In this first episode we open bm Studio and build the three models of the game from blocks: Pico the gecko, an apple and a wooden crate.

What you learn:
- Open bm Studio from the Dev tab and start a new project
- Place blocks with Space, change level with PgUp / PgDn, turn the view with Q / E
- Pick a flat colour for the brush (Tab, C, Enter)
- Name models on the F2 page (N new, R rename)
- Move corners with the vertex tool (4, G)
- Select faces and move them (3, Space, G)
- Reduce triangles with the minus key and stay inside the budget: Pico 300, Apple 80, Crate 40
- Save the project with Ctrl+S

Main keys: F1 build, F2 models, 1 block, 3 select, 4 vertex, Space, Backspace, PgUp, PgDn, Q, E, Tab, C, G, minus, Ctrl+Z, Ctrl+S.

Everything is made on the console itself: no Blender, no files made outside.
