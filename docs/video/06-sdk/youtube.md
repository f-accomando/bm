## Titolo (52 caratteri)

Tropic Trail 6: 3D Lights, Fog and Shadows in bm SDK

## Descrizione (English)

Tropic Trail is a 3D platformer built only with the tools inside the bm console. In this episode we gather the work of the earlier videos in bm SDK, the hub of the bm suite: the models, the level map and the sounds are already in the cartridge, and we light the jungle.

You will see the 3D with models template, how to set the game screen to 480x270 (an exact 4x on a 1080p TV), and the five calls that change the look: sky3d for the sun and sky colours, fog3d for the fog, lamp3d for a lantern, draw3d with flag 8 and shadow3d for the shadow under Pico. We run it with F5, look at the dev kit page, and build the game with Ctrl+B. Every value we use is on screen.
