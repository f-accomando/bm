Tropic Trail 2: bm Pixel Textures and Painting a 3D Model

## Descrizione

Tropic Trail is a 3D platformer built only with the tools inside the bm console. In this episode we draw the textures of the game in bm Pixel (grass, path, rock, wood, Pico's skin, the apple and an apple icon for the score), then go back to bm Studio and paint them on the models.

What you learn:
- Open a project in bm Pixel and set the sprite size to 16x16
- Load the palette of bm Studio so colours match the models
- Fill (G), pencil (B), line (L) and filled oval (O)
- Copy and paste a sprite (Ctrl+C, Ctrl+V, Enter)
- Put a tile on the faces of a model (select tool, A, Tab, Enter)
- Paint the pixels of a face's tile directly on the model (tool 5)

Main keys: F1 / F2 / F3, Z, G, B, L, O, PgDn, Ctrl+C, Ctrl+V, Ctrl+S in bm Pixel; 3, A, Tab, Enter, 5, C, Space, E in bm Studio.

Everything is made on the console itself.
