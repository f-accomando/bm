Tropic Trail 5: Soft Game Sounds and a Jungle Song in bm Sound

## Descrizione (English)

Tropic Trail is a 3D platformer built only with the tools inside the bm console. In this episode we use bm Sound, the sound editor of the console, to make everything Pico hears: six soft sound effects (APPLE, CRATE, JUMP, STEP, SPIN, HIT) and a one-minute jungle song called JUNGLE.

You will see how to build an instrument with a wave, an envelope, a filter, a little room and echo; how to write an effect as a row of notes; how to write a pattern on six tracks; and how to order patterns into a song that loops. We keep tracks 7 and 8 empty so the effects never cut the music, and we say honestly what the synthesizer cannot do.
