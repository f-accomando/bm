# Archive: the retired sync system

The sync system is retired. Do not use it for new work.
The full history is on the remote branch `sync/protocollo-ottobre`. It holds the work orders, inboxes, ledgers, and `NEXT.md`.
This folder keeps the protocol files, the sync tools (`tools/`), their tests (`tests/`), and the SPV hook (`hooks/`).
The tools and tests here are not run by `make test-docs`. Copy a file back to its old path to run it.
Agents and routing stay active: see `docs/agents/routing.md`.
