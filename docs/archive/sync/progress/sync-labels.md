# Sync protocol: English and Italian labels

Closed sync files and the older tools use the Italian labels.

| English | Italian |
|---|---|
| `## Deliveries` | `## Consegne` |
| `## Profile` | `## Profilo` |
| `## Requirements` | `## Requisiti` |
| `## Closing` | `## Chiusura` |
| `verify:` | `verifica:` |
| `open: ... none` | `aperti: ... nessuno` |
| `waiting_on: user` | `waiting_on: utente` |
