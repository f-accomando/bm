# Beta hardware tests (only the user can run them)

This document collects the 13 verification checks that require physical hardware (the RGB30 console or the Raspberry Pi Zero W). Automated emulator runs in QEMU verify syntax and logic, but cannot substitute tests on real silicon, displays, and controller inputs.

## How to use

When a test succeeds on the physical device, open the corresponding entry in `docs/spec/divergences.toml` or under `Open work` / `To do` in the referenced area progress document, and update it as indicated in the "if OK" column. If a check fails, open an issue including the relevant log lines from `bm/bootlog.txt`.
