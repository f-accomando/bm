Obiettivo: generare da docs/api/*.md un unico file con nome, firma, area e testo di ogni funzione, e un test che ne confronti i nomi con la tabella api[] del runtime.

## AGY-1a — generatore (bm-coder, 40 min)
- scripts/mkapi.py: legge docs/api/*.md in ordine alfabetico. Ogni riga che corrisponde a ^\| (.+?) \| (.*) \|\s*$ dà la prima cella (firme) e la seconda (testo). Dalla prima cella si estraggono tutti gli span tra backtick; ogni span che corrisponde a ^([A-Za-z_]\w*(?:[.:][A-Za-z_]\w*)*)\s*\(.*\)$ è una voce: name = gruppo 1, signature = lo span intero, area = nome del file senza .md, text = seconda cella con tab e a-capo sostituiti da uno spazio. Una riga con più firme (es. "`pset(x, y, c)` / `pget(x, y)`") dà più voci con lo stesso testo.
- Duplicati: vince la prima voce (ordine file, poi riga); per le altre stampa su stderr "dup <name> <file>:<riga>".
- Output src/ai/api.tsv: prima riga "# generated by scripts/mkapi.py from docs/api/*.md: do not edit", poi "name\tsignature\tarea\ttext" ordinato per name, a-capo \n, UTF-8.
- CLI: senza argomenti scrive il file; --check esce con 1 (e stampa "api.tsv is stale") se il file è diverso da quello che genererebbe, altrimenti 0; --names stampa i nomi, uno per riga.
- Verifica: python scripts/mkapi.py && python scripts/mkapi.py --check → exit 0.

## AGY-1b — test di confronto con runtime.c (bm-coder, 35 min)
- tests/tools/test_mkapi.py (unittest, con unittest.main() in fondo come tests/tools/test_agent_audit.py):
  (1) parser su un .md di fixture in una cartella temporanea: la riga con due firme dà due voci; una riga senza "(" nella prima cella non dà voci; un duplicato finisce su stderr;
  (2) subprocess "mkapi.py --check" → returncode 0;
  (3) da src/bm/runtime.c prende il blocco tra "static const luaL_Reg api[] = {" e il primo "{ NULL, NULL }" e i nomi con la regex \{ "([A-Za-z_0-9]+)", l_ ; i nomi globali di api.tsv sono quelli senza "." né ":". Asserzioni: runtime − doc == UNDOCUMENTED e doc − runtime == NOT_IN_RUNTIME, due set costanti nel test riempiti con le differenze reali trovate al primo giro (nessuna correzione a docs/api né al runtime).
- Verifica: python tests/tools/test_mkapi.py → OK, exit 0; python scripts/mkapi.py --check → 0.
Criterio di fine: i due comandi di verifica passano; il DELIVERED elenca UNDOCUMENTED e NOT_IN_RUNTIME (numero e nomi) da far decidere a SPV.
