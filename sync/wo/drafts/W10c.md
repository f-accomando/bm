## Change (no open design choices)
1. `src/gpu/gpu3d.c`: before `gpu3d_init`, `static int cb_pfx_step(void *ctx, float *a, int cap, float g)`: `(void)ctx;` return 0 if `G.failed || !v3d_qpu_ok() || gpu3d_inflight() || cap < 16 || cap % 16`; lazily `static uint32_t *qcode; static uint32_t (*qunif)[8];` allocated once with `aligned_alloc(64, ...)` (code: `sizeof qpu_pfx_step`, copied from `shaders.h`; unif: 4 blocks of 8 words); `blocks = cap / 16`; `nq = blocks % 4 == 0 ? 4 : blocks % 2 == 0 ? 2 : 1`; for i < nq: `qunif[i][0] = v3d_bus(a); [1] = cap; [2] = i * (blocks / nq); [3] = blocks / nq; [4] = bits of g` (via `memcpy` into a `uint32_t`); `return v3d_qpu_run(v3d_bus(qcode), v3d_bus(qunif), 5, nq, 20000) == 0;` (on -1 the ARM runs: the pool was not changed unless the QPUs stored a part; to keep the "same result" promise, copy the pool first into a static scratch `float *keep` (7 * cap floats, allocated like the others) and copy it back on -1, then return 0). In `gpu3d_init` next to `G.backend.zclear = cb_zclear;` add `G.backend.pfx_step = cb_pfx_step;`.
2. `tests/gpu/test_gpu3d.c`: `static void test_pfx(void)` called at the end of `main`, after W09d's checks: `gpu3d_init()` has run; two pools of 4096 made with `r3d_pfx_new(4096)` whose `a` is then replaced by `test_aligned_alloc(64, 7 * 4096 * 4)` memory holding the same fill as W10a's test (copy that fill into a helper `pfx_fill(r3d_pfx_t *)` and use it in both tests if W10a's is in this file); pool A stepped 5 times with `r.backend = gpu3d_backend()`, pool B 5 times with `r.backend = NULL`; `CHECK(memcmp(A->a, B->a, 7 * 4096 * 4) == 0, "the QPU pool and the ARM pool differ")`; then `v3d_qpu_set_ok(0)`: pool C stepped 5 times with the V3D backend (the fallback path) `CHECK(memcmp(C->a, B->a, ...) == 0, "the fallback pool differs")`, `v3d_qpu_set_ok(1)`; then the pixels: draw A and B with `r3d_pfx_draw` into two pages as `s_grid` sets up its page and camera (backend NULL for both: the points are the ARM's), `CHECK(memcmp(pageA, pageB, bytes) == 0, "pixels differ")`, and `CHECK(pixels > 0, "nothing drawn")` (the camera must see the points: use the `s_grid` camera and scale the fill so some x, y, z fall in view; if none shows, report the camera).

## Open decisions (for SPV before assigning)
1. On the Pi the copy to `keep` costs ARM time (about the step itself for 4096 particles): the QPU step pays off for larger pools or when the ARM is busy; H7/3D Bench decides whether to drop the `keep` copy once the QPU path is trusted.
2. The step refuses to run while a queued frame is in flight (returns 0, the ARM steps): with `gpu3d_queue` on, most frames hit the ARM path. A `gpu3d_sync()` first would stall the queue; not done here.
