## Change (no open design choices)
1. `src/rgb30/mali.h`: `mali_draw_t` gets a field `const float *mvp;   /* NULL: xyz are pixels (phase 2); else a 4x4 matrix by rows, xyz are model-space and the GPU transforms them (phase 3) */` as its LAST field (existing initialisers `{ xyz, n, rgb }` keep working).
2. `src/rgb30/mali.c`: places `MEM_VS3 0x4a00` (code of `BM_VS3`, 128-aligned: check the free space between `MEM_VS` and `MEM_FS` in the base; if `0x4a00` is taken, take the next free 128-aligned place and say which), `MALI_FRAME_VPUSH 0x38000` (16 floats a draw, 64 bytes a draw, so draws up to 64 use `0x38000..0x39000`), the vertex-side uniform buffer descriptor per draw inside its 0x400-byte block (`+ 0x80`). In `frame_build`: copy `BM_VS3_bin` to `MEM_VS3` when any draw has an `mvp`; for such a draw a second vertex Renderer State in its block (`+ 0x200`) from `BM_VS3_*` (`.shader = pa + MEM_VS3`, `.ubo_count = BM_VS3_UBO_COUNT`, `.push_count = BM_VS3_PUSH_COUNT`, as the phase-2 one does for `BM_VS_*`), the 16 floats at `MALI_FRAME_VPUSH + 64 * d`, `md_uniform_buffer(block + 0x80, pa + MALI_FRAME_VPUSH + 64 * d, 4)` (4 entries of 16 bytes), and its vertex Draw `vd` with `.state = <that state>`, `.uniform_buffers = pa + block + 0x80`, `.push_uniforms = pa + MALI_FRAME_VPUSH + 64 * d`; the push map says words 0..15 are bytes 0..60 of ubo 0 (`BM_VS3_push`): use it, do not assume. A draw without `mvp` is built exactly as before (byte for byte: the test compares).
3. `tests/rgb30/mali_test.c`: `test_matrix_image()` after W12's test: a frame of two draws, the first with `mvp` = a matrix `{ 2,0,0,10, 0,3,0,20, 0,0,1,0, 0,0,0,1 }`, the second without; CHECK: (a) the 16 floats at `MALI_FRAME_VPUSH` equal the matrix; (b) the first draw's vertex job references a Renderer State whose `shader` field (use `md_renderer_state` into a temp with the same input and `memcmp`) is the `MEM_VS3` address and the second's the `MEM_VS` one; (c) a frame whose draws all lack `mvp` leaves the bytes at `MEM_VS3` untouched (still zero from the memory the test cleared) and builds the same vertex Renderer State as in W12's test;
   (d) `mali_frame` refuses `mvp` with `n` over the limit as before.
