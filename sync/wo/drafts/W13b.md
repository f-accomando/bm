## What exists today (found with git grep on the base)
- Triangles reach the backend in two places: `emit()` (`src/bm/r3d.c:1072-1078`: a triangle or the two of a clipped quad; `kind`, `tex`, `nodepth`) and `emit_fan()` (`:2377-2383`: effects and shadows, always `R3D_DEPTH_TEST`). `to_arm(r, why)` (`:839-847`) calls the hook, sets `r->backend = NULL` and clears the z-buffer. Backend meshes and shadows go through the optional `mesh` (`:1977`, `:2019`) and `shadow` (`:1885`) callbacks, which a backend may leave NULL.
- The backend struct: `src/bm/r3d.h:141-172`; `tex_screen` is the model of a capability flag.
- `tests/bm/test_bm.c`: `test_3d()` builds an `r3d_t`, meshes and draws; the checks are counted by `checks`/`fails`.

## Change (no open design choices)
1. `src/bm/r3d.h`, in `r3d_backend_t` after `tex_screen`: `int colour_only;           /* M41: draws flat colours with depth R3D_DEPTH_WRITE only (the Mali, phase 2): anything else makes r3d hand over to the ARM (to_arm) */`.
2. `src/bm/r3d.c`: a helper before `emit`: `static int colour_ok(r3d_t *r, int kind, int depth, const char *why) { if (r->backend->colour_only && ((kind & 3) != R3D_KIND_COLOUR || depth != R3D_DEPTH_WRITE)) { to_arm(r, why); return 0; } return 1; }`; `to_arm` is defined before `emit` (`:839` < `:1072`): if not, move the helper after it. In `emit` first line: `if (!colour_ok(r, kind, nodepth, "textures, screen-door faces or effects (the Mali draws flat colours)")) return;`; in `emit_fan` the same with `R3D_DEPTH_TEST` (always hands over for a `colour_only` backend). The mesh and shadow paths need nothing: a backend with `colour_only` has no `mesh`/`shadow` callback.
3. `tests/bm/test_bm.c`: `test_colour_only()` called from `main` after `test_3d()`: a fake backend `{ .tri = count_tri, .zclear = nop, .colour_only = 1 }` (the `tri` increments a counter), an `r3d_t` with a hook counting its calls and recording `why`, as `test_3d` sets up its scene; (a) a mesh with flat colours: the counter rises, the hook is not called; (b) a textured mesh (as `test_3d` draws one): the hook is called once with a `why` containing `textures`, `r->backend == NULL` afterwards; (c) the same scene with `colour_only = 0`: the textured triangles reach the fake backend and the hook is not called; (d) `r3d_point` (an effect) with `colour_only = 1`: the hook is called.
