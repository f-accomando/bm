## Change (no open design choices)
1. `src/gpu/v3d.h`, after `v3d_wait`'s declaration: 
```
/* M44: user QPU programs. Runs `count` (1..12) copies of the program at bus address `code` on that many QPUs,
 * the i-th with the `nunif` uniform words at `unif + 4 * nunif * i` (bus addresses); waits for all of them,
 * at most `timeout_us`. 0, or -1 (timeout, queue error or a program the emulator refuses; the registers are
 * kept for v3d_dump). Not while a 3D job is in flight. Needs v3d_qpu_ok() (the start-up probe, W09d). */
int v3d_qpu_run(uint32_t code, uint32_t unif, uint32_t nunif, int count, uint32_t timeout_us);
int v3d_qpu_ok(void);                   /* the start-up probe saw a user program work (W09d) */
void v3d_qpu_set_ok(int ok);            /* the probe's verdict */
```
2. `tests/gpu/v3d_emu.c`: (a) in `qpu_t` add `uint32_t dma_setup; int dma_pending;`; in the `waddr == 49` file-B case, when `v >> 30 == 2` store `q->dma_setup = v` (the DMA store setup) and do not treat it as a VPM write address; (b) a new case `waddr == 50` file B: take UNITS (rows), DEPTH (words) and the VPM row from `dma_setup` (fields as in the Reference Guide table the W09a program used; the emulator and W09a must read the SAME fields: copy the field list from W09a's comment), copy that many VPM rows to `ptr(addr)` (`err("QPU: DMA store outside memory", ...)` if `ptr()` is NULL), and mark `dma_pending = 0`; a read of regfile B 50 (`vw_wait`) is accepted; (c) `int v3d_qpu_run(...)` implemented as: `if (count < 1 || count > 12) return err("QPU: %u programs", count, 0)`; for i in 0..count-1: `memset(&q, 0, sizeof q); q.unif = ptr(unif + 4 * nunif * i); q.nunif = nunif; q.vpm = static vpm array of QPU_VPM_ROWS rows; if (qpu_run(&q, ptr(code), 512) != 0) return -1;` (`timeout_us` is ignored by the emulator except: if the program reaches 512 instructions without `thrend`, `qpu_run` already returns -1 and that is the timeout); `static int ok_flag = 1; int v3d_qpu_ok(void) { return ok_flag; } void v3d_qpu_set_ok(int ok) { ok_flag = ok; }` (the emulator's user QPUs work from the start; a test may set 0 to try the fallback).
3. `tests/gpu/test_gpu3d.c`: a function `static void test_qpu_user(void)` called at the end of `main` before its summary: allocate with `test_aligned_alloc(64, ...)` an output buffer of 48 words filled with `0xDEADBEEF`, a uniform block of 3 x 2 words (`{ v3d_bus(out + 16*i), 100 + i }`), `qpu_user_store` copied from `src/gpu/shaders.h` (include it as `gpu3d.c` does; `static const uint32_t qpu_user_store[...]`); `CHECK(v3d_qpu_run(v3d_bus(code), v3d_bus(unif), 2, 3, 1000000) == 0, "qpu_user_store: %s", emu_error)`; for i in 0..2, lane l in 0..15: `CHECK(out[16*i + l] == 100 + i + l, ...)` (one CHECK per QPU comparing all 16, to keep the count small); then a program that never ends: 600 `nop` instructions (two zero words each) with no `thrend`, in an aligned buffer: `CHECK(v3d_qpu_run(...) == -1, "a program that does not end must fail")`.
